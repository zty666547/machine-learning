## 导入

从仓库根目录运行：

```bash
python scripts/import_bacillus_data.py \
  --data-root /path/to/promoter \
  --output-dir data/processed/bacillus_subtilis
```

输出 `classification.csv`、`strength.csv` 和 `audit.json`；行号对应原始文件，强度输出保留两个原始数值字段。审计文件包含源文件路径、SHA-256、长度分布和冲突行号。源数据及处理结果按仓库约定不提交 Git；组员使用同一课程包执行命令即可复现。当前未训练新的物种模型，也未更改原有大肠杆菌划分或结果。
