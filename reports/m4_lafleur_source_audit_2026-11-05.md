# M4：合成启动子体外转录数据的可行性与重叠核查

日期：2026-11-05。本轮寻找此前未用于本项目模型评分的另一项实验数据，核查来源、序列窗口、质量标记和已用数据的有限范围重叠。**本轮没有运行预测器，也没有计算预测性能指标。**

## 1. 总体结论

找到 [LaFleur 等人的合成启动子研究](https://doi.org/10.1038/s41467-022-32829-5)。作者使用大肠杆菌 RNAP/σ70 体外转录实验研究合成启动子，公开了序列模块、转录速率和 TSS 测量相关数据。这个实验来源不同于本项目训练使用的天然启动子数据，也不同于此前探索过的 Urtecho 外部 TSS 片段，但实验体系差异较大。

作者补充表中有 13,481 条记录，其中 **5,193 条**被标为 `high quality = Yes`。这 5,193 条均可以从设计模块构造名义 50 bp 窗口；按本轮限定的偏移和编辑距离规则，与课程数据及此前已评分外部序列均**未发现匹配**。

它是一份值得继续核查的候选来源，但当前还不能称为已经确认独立且直接可用的最终测试集：名义窗口的截取位置尚未逐条核对为实测 TSS；合成序列共享设计骨架，且实验条件与课程任务不同。

## 2. 数据来源和实验差异

原始文件为论文 [Supplementary Data 1](https://static-content.springer.com/esm/art%3A10.1038%2Fs41467-022-32829-5/MediaObjects/41467_2022_32829_MOESM5_ESM.xlsx) 的 `La Fleur et al (Fig 1d, S1)` 工作表，SHA-256 为：

```text
1ecea7264ba51ad7f6b51c716cccc18141cdb2f8c1b50fbeb5dfe3c6700b67e1
```

研究中的 5,193 条高质量数据依据作者的读数与 TSS 条件筛选；本轮沿用工作表内现成的标记，没有声称自己复现了作者的全部质量过滤。论文描述了体外 RNAP/σ70 转录测量及序列模块；本项目课程数据则是另一实验背景下的天然序列及转录水平代理。两者的数值、环境、调控因素、输入片段上下文不应直接视为一致。

本轮只检查了标签是否为有限正数等数据可用性，**未将标签和本项目预测器分数进行比较**。由于作者质量标记和标签可用性已被查看，不应称为完全盲态数据；后续若要做模型评价，需在查看结果前另行固定数据处理、重复记录和评价方案。

## 3. 名义窗口如何构造

工作表将序列分为 `UP`、`h35`、`spacs`、`h10`、`disc` 和 `ITR`。按该顺序拼接，将设计给出的 ITR 起点作为**名义位置**，取其前面 50 个碱基作为候选窗口。研究将 ITR 描述为起始转录区域；但真实 TSS 可能因序列变化而偏移，原始 TSS 表的坐标约定尚未逐条核实。

因此这里的 50 bp 是基于序列模块的**设计位置近似**，不能写成每条序列均已按实测 TSS 截取。5,193 条高质量记录的拼接序列长度为 72–79 bp；名义起点在拼接序列中的零起始下标为 51–58，全部可提取名义窗口。

| 数据检查 | 结果 |
| --- | ---: |
| 原表记录 | 13,481 |
| 作者标记高质量 | 5,193 |
| 高质量记录中可提取名义 50 bp 窗口 | 5,193 |
| 高质量记录中转录速率为有限正数 | 5,193 |
| 不同名义 50 bp 窗口 | 4,489 |

## 4. 重叠和重复记录

规则运行前已固定：对每个名义 50 bp 窗口，检查可用的 ±5 bp 截取偏移，分别比较原方向和反向互补方向；与课程数据全部 11,884 条序列及此前已评分外部数据的 1,541 个不同窗口比较。采用完整 50 bp 的全局编辑距离，替换、插入、删除各计 1 次，阈值为最多 5 次。

在该**有限规则**下，5,193 条均未检出与上述参考序列匹配。由于部分原序列上游不足，不能对每条都检查完整的 11 个偏移：

| 每条记录可检查的偏移位置数 | 记录数 |
| --- | ---: |
| 7 | 20 |
| 8 | 3,990 |
| 9 | 45 |
| 11 | 1,138 |

因此，“未检出”只适用于实际可取到完整 50 bp 的偏移窗口和本轮阈值；不排除其他偏移、更多编辑、其他长度、共享骨架、同源关系或实际 TSS 偏移带来的关联。

5,193 条记录中存在 **227 组**重复名义 50 bp 窗口，涉及 **931 条记录**；这 227 组每一组都包含不同的完整拼接序列。也就是说，相同模型输入可能对应不同的下游 ITR 或其他完整序列上下文；不能直接把这些记录当成完全独立的模型输入，也不应未经约定就合并强度值。

## 5. 校验与下一步

- 固定了来源文件、此前已评分外部记录和课程数组的校验值；名义窗口位置及上下文重复情况均保存在逐条审计文件中。输出文件不包含外部实验强度值。
- 项目测试覆盖名义窗口的模块拼接、位置和边界；抽取 5 条分别覆盖所有名义起点位置的记录，将其所有可用偏移和双方向窗口与 13,425 个不同参考序列逐一使用全局编辑距离穷举比较，结果与索引筛查一致。抽查不等于对全部记录进行穷举。
- 同一环境下重复运行本轮程序，汇总 JSON 与逐条 CSV 一致；未使用本项目模型打分或按预测表现筛选候选。
- 下一步应优先核实补充表的 TSS 坐标约定与实测起始位点、确定重复名义输入及不同 ITR 上下文如何处理；若仍计划评估，应先固定候选、统计单位及指标，并清楚报告体外与细胞内实验的差异。
