# M4 训练数据：位置加权近邻探索

## 方法

上一轮按等权汉明距离寻找跨簇最近邻。本轮尝试让与强度相关的位置获得更高权重：对每个训练折，在拟合集内计算每个位置单独按 A/C/G/T 分组时能解释的 log10 强度方差比例 R²，设位置权重 `1 + 10 × R²`；每条查询用这些权重计算逐位置不匹配的加权距离。该数值的倍数在运行前固定，见[配置](../configs/m4_weighted_neighbor_2026-11-08.toml)。

位置权重仅由本折拟合部分的数据和标签计算；查询折不参与权重计算。距离并列（浮点容差 1e-10）时取最近邻标签均值。等权基线和加权方法使用相同训练数据与跨簇折。开发验证时仅用完整训练集确定权重。

## 结果

训练集 8,318 条，固定相似性簇三折折外结果：

| 指标 | 等权最近邻 | 位置加权最近邻 |
|---|---:|---:|
| MAE | 0.61661 | 0.65393 |
| Pearson | 0.06887 | 0.06619 |
| Spearman | 0.04547 | 0.04199 |
| 弱组 MAE | 0.61293 | 0.62105 |
| 中组 MAE | 0.42228 | 0.47758 |
| 强组 MAE | 0.81457 | 0.86309 |

开发验证 MAE 为 0.57103 和 0.60521；该集合此前被反复用于开发，不是独立评价。

**关键解释：**折外等权最近邻存在并列的查询有 3,130 条；预测发生变化的 3,128 条全部来自这些并列查询。对于等权下最近邻唯一的查询，预测没有变化。等权方法会平均并列邻居标签；位置加权通常打破并列，减少可平均的标签数，因此本轮误差增加同时混合了位置权重和并列平均方式的影响，不能单独归因于位置权重无效。

每折位置权重约在 1.000–1.078 内，差异不大。它们只反映训练样本中每个位置单独与标签的关系，不是生物学上的位置重要性证明，也无法衡量位置之间的交互或 motif 作用。未检验其他加权倍数，也没有把测试集用于方法选择。

## 数据与复现

训练集 8,318 条、开发验证集 1,783 条；固定相似性簇三折，每折拟合集包含原 fit 和 early 样本。弱、中、强的评价边界由训练标签三分位数确定。测试数据只由加载器检查格式，没有提取测试特征或计算测试指标。本轮无外部数据和湿实验，不替换融合筛选器。

```sh
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 VECLIB_MAXIMUM_THREADS=1 \
 python scripts/audit_weighted_neighbors.py --data-dir "$DATA_DIR" \
 --output reports/m4_weighted_neighbor_2026-11-08.json
```

[完整结果](m4_weighted_neighbor_2026-11-08.json)包括每折位置权重、数据摘要和分组指标；不导出训练序列。
