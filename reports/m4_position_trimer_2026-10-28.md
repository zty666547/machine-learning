# M4：位置 3-mer 强度预测实验

日期：2026-10-28。实验检验把 3-mer 的具体位置加入线性预测器，能否改善现有强度预测。**本轮模型总体未超过 M3 融合筛选器，因此不替换它。**

## 方法

- 一条 50 bp 序列有 48 个三碱基窗口；每个位置有 64 种可能，共 48 × 64 = 3,072 个二值特征。采用无标准化的独热编码、带截距的岭回归，以 `log10(强度)` 为预测目标。正则化参数 α 越大，模型系数受约束越强；此处 α 与此前经过标准化的岭回归 α 不可直接比较。
- 基于固定的 90% 相似性簇划分，在 8,318 条训练集内按簇三折交叉验证，以折外总体 MAE 从 α = 1、10、100、1,000、10,000、100,000 中选参数。最初的搜索在 1,000 达到上界，随后依据训练折外结果扩展到 100,000；由于开发验证结果已被查看，这仍是探索性工作。
- 使用分折种子 20261028、20261029、20261030 分别重复训练集内参数选择，三次都选中 α = 1,000。最终模型在同一完整训练集上重新拟合，三次参数相同，故验证结果相同；这不是三次独立外部评估。
- 实验只对训练和验证样本构建特征与计算指标。读取课程原始数组时会包含测试记录的格式检查，但没有用测试数据调参或计算测试指标。

## 结果

训练集内部三折的折外 MAE：α = 1、10、100、1,000、10,000、100,000 分别为 0.58810、0.54194、0.47755、0.46910、0.47646、0.47796（种子 20261028）。同一折外划分中，预测训练均值的常数基线 MAE 为 0.47814。另两组分折下，α = 1,000 的折外 MAE 分别为 0.46833、0.46801。

固定开发验证集上的比较如下，MAE、RMSE 单位为 log10 强度：

| 方法 | MAE ↓ | RMSE ↓ | Pearson ↑ | Spearman ↑ | 弱组 MAE ↓ | 中组 MAE ↓ | 强组 MAE ↓ |
|---|---:|---:|---:|---:|---:|---:|---:|
| M3 融合筛选器 | 0.43155 | 0.57369 | 0.28657 | 0.26277 | 0.47295 | 0.17238 | 0.65693 |
| 位置 3-mer 岭回归 | 0.44668 | 0.58370 | 0.23330 | 0.23024 | 0.53888 | 0.17212 | 0.63887 |

预测训练均值的常数基线验证 MAE 为 0.45742。位置 3-mer 预测器优于该常数基线，但整体 MAE 和相关性均不如融合筛选器；强组 MAE 略低、弱组明显更高。预测值标准差与真实标签标准差之比为 0.14395，低于融合筛选器的 0.26968，预测更集中于中间范围。

这不能单独证明“3-mer 位置信息无效”：本次比较的模型形式、特征组合、正则化和选型过程均不同，并非只改变一个变量的严格消融。M3 融合模型曾在同一验证集上选择权重，CNN 也使用该验证集早停；验证集已多次用于开发，以上结果不能代表全新独立测试。三个随机种子仅改变训练集分折。原测试集在早期已被查看，不能声称为完全未接触的最终测试集。

## 复现与文件

```bash
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 VECLIB_MAXIMUM_THREADS=1 \
python scripts/evaluate_position_trimer_ridge.py \
  --data-dir /path/to/promoter/strenth/data \
  --seed 20261028 \
  --output reports/m4_position_trimer_seed_20261028.json \
  --model-output outputs/m4_position_trimer/model_20261028.npz
python -m unittest discover -s tests -v
```

运行需要 Python 3.11 或更高版本（仓库配置读取使用 `tomllib`）和 NumPy。岭回归使用共轭梯度求解，不生成稠密的 3,072 维设计矩阵；测试用小规模数据与标准稠密岭回归结果比较，并验证编码、分折、模型保存和加载。模型文件位于 Git 忽略的 `outputs/`，可通过脚本重新生成。结果：[20261028](m4_position_trimer_seed_20261028.json)、[20261029](m4_position_trimer_seed_20261029.json)、[20261030](m4_position_trimer_seed_20261030.json)。
