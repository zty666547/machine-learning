# M4：GRU 结构与 Huber 损失的强度预测探索

日期：2026-11-06。本轮不只调整 CNN 参数，而是比较两种不同方向：**引入门控循环结构 GRU**，以及**改变普通 RNN 的训练损失函数**。实验设置见计算前固定的 [配置](../configs/m4_gru_loss_2026-11-06.toml)。

## 1. 主要结论

- **GRU**：相对于普通 RNN，训练折外 MAE 均值从 0.46343 小幅降至 0.46234；但三个种子并非都改善，仍高于同条件 CNN 的 0.46050。它在开发验证集强组的均值误差较低、弱组误差更高，但没有解决预测范围收缩。
- **RNN + Huber 损失**：相对原 RNN 的训练折外 MAE 均值从 0.46343 降至 0.45832，三个种子均下降；然而 Pearson 降低、预测范围进一步收缩，强组 MAE 从 0.75293 增至 0.79255。整体 MAE 变好不能等同于强度控制或排序更好。
- 因两种方案仍有明显取舍，且开发验证集此前多次使用，本轮**不自动替换现有融合筛选器**。该结果也不能推广成所有 GRU、Huber 设置或序列模型的结论。

## 2. 本轮具体改了什么

**方案一：GRU。** 普通 RNN 每次读取新碱基后更新隐藏状态；GRU 增加更新门和重置门，让模型在训练中学习如何组合已有状态和新输入。本轮使用单层、单向、27 维隐藏状态，将每一步状态按 5 个位置区间平均后接 64 单元预测头。参数量 **11,361**，与此前 CNN 的 11,297、普通 RNN 的 11,553 接近，但结构不同、并非完全相同参数量的因果消融。

**方案二：Huber 损失。** 沿用普通 RNN 结构，只把训练损失由均方误差（MSE）改为 Huber：较小误差使用二次形式，较大误差的梯度不再随误差绝对值继续线性增大。阈值 `delta=1` 应用于每个训练子集**标准化后的 log10 强度**，而非原始实验单位。强弱端样本不一定是异常值；减小大误差的影响也可能加重两端预测误差，需要通过分组结果判断。

## 3. 对照和数据边界

- 使用课程大肠杆菌 50 bp 序列，固定训练集 8,318 条、开发验证集 1,783 条，标签为 `log10(课程强度)`。
- 复用上一轮相似性簇训练内三折和每折内部早停分组；三个模型随机种子为 20260912、20260913、20260914。相同样本在相同种子下与前一轮 CNN 和 MSE-RNN 配对比较。旧结果的课程数据、划分、配置及 NumPy 版本哈希或版本均经核验。
- 两种新方案均使用相同学习率、批大小、早停 MAE 和训练子集目标标准化；GRU 为 MSE，Huber-RNN 与原 RNN 的结构及其他训练设置相同。GRU 和 RNN 都使用梯度裁剪。
- 原始数组读取仅做格式校验；测试序列没有进入特征、拟合或指标。该测试集在项目早期曾被查看，不是未经接触的最终测试集。开发验证集此前也多次用于开发，本轮不用于早停或自动选型。
- 各数值为三个**共享同一分折和数据的模型随机种子**的均值 ± 总体标准差，不是三套独立数据，也不构成统计显著性证明。

## 4. 整体指标

MAE、RMSE 在 `log10(课程强度)` 尺度上；越低越好。Pearson、Spearman 衡量相关或排序，越高越好。

| 数据 | 策略 | MAE ↓ | RMSE ↓ | Pearson ↑ | Spearman ↑ |
| --- | --- | ---: | ---: | ---: | ---: |
| 训练折外 | CNN（原结果） | 0.46050 ± 0.00077 | 0.62907 | 0.19842 | 0.17743 |
| 训练折外 | 普通 RNN + MSE（原结果） | 0.46343 ± 0.00257 | 0.63333 | 0.16777 | 0.15197 |
| 训练折外 | **普通 RNN + Huber** | **0.45832 ± 0.00068** | 0.63728 | 0.15967 | 0.15624 |
| 训练折外 | GRU + MSE | 0.46234 ± 0.00085 | 0.62927 | 0.18292 | 0.16557 |
| 开发验证 | CNN（原结果） | 0.43718 ± 0.00123 | 0.59282 | 0.22246 | 0.19249 |
| 开发验证 | 普通 RNN + MSE（原结果） | 0.44294 ± 0.00362 | 0.59417 | 0.19116 | 0.17423 |
| 开发验证 | 普通 RNN + Huber | 0.43724 ± 0.00302 | 0.59927 | 0.16374 | 0.16038 |
| 开发验证 | GRU + MSE | 0.44238 ± 0.00128 | 0.59363 | 0.18752 | 0.16844 |

Huber-RNN 的三个配对种子训练折外 MAE 分别比 MSE-RNN 低 0.00321、0.00368、0.00847；但是 RMSE 均值变大、Pearson 均值下降。GRU 相对 MSE-RNN 的三个折外 MAE 差值依次为 −0.00057、+0.00077、−0.00347，方向不完全一致。原 CNN 与 RNN 作为固定参考，不用本轮外部数据重新选权重。

## 5. 强弱组与预测范围

以下按训练集三等分边界，对训练折外预测按**真实标签**回顾分组；不同指标的取舍比总体 MAE 更值得关注：

| 策略 | 弱组 MAE | 中组 MAE | 强组 MAE | 预测标准差 / 标签标准差 |
| --- | ---: | ---: | ---: | ---: |
| CNN | 0.46674 | 0.16668 | 0.74797 | 0.24708 |
| 普通 RNN + MSE | 0.47407 | 0.16319 | 0.75293 | 0.23923 |
| 普通 RNN + Huber | 0.44329 | 0.13899 | 0.79255 | 0.18276 |
| GRU + MSE | 0.48466 | 0.16088 | 0.74137 | 0.22103 |

Huber 在该对照中改善了弱组和中组 MAE，却加重强组低估，且预测分布比 MSE-RNN 更窄。三个种子下强组折外 MAE 均有增加；只能说该现象在本次共享分折的重复中出现，不能解释成普适规律。

开发验证集结果同样有取舍：MSE-RNN、Huber-RNN 和 GRU 的强组 MAE 均值分别为 0.70568、0.75389、0.70231，弱组为 0.45423、0.42240、0.45834。完整偏差和标准差见 [汇总结果](m4_gru_loss_summary_2026-11-06.json)。

## 6. 实现和检查

新增 NumPy [GRU 预测器](../src/promoter_ml/models/gru_strength.py)及普通 RNN 的 Huber 目标；不增加 PyTorch 等依赖。[候选打分脚本](../scripts/score_rnn_strength.py)支持通过 `--model-type gru` 加载 GRU，也保留原 RNN 用法。

GRU 的时间展开梯度和 RNN-Huber 梯度使用有限差分核对；单元测试还覆盖 Huber 公式、合成任务学习、GRU 参数保存加载及打分接口。修改 RNN 后，种子 20260912 的原 CNN/RNN 配对实验重跑结果与上一轮 JSON 一致。

三个新模型种子均完成训练；种子 20260912 的两种策略完整重跑后指标 JSON 和检查点参数一致。本地 `outputs/m4_gru_loss/` 中的检查点是训练内拟合加早停得到的**实验模型**，不是最终生产版本，不纳入 Git。

## 7. 复现

```bash
export OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 VECLIB_MAXIMUM_THREADS=1
for seed in 20260912 20260913 20260914; do
  python scripts/evaluate_gru_loss_strategies.py \
    --data-dir /path/to/promoter/strenth/data --seed "$seed" \
    --output "reports/m4_gru_loss_seed_${seed}.json" \
    --checkpoint-dir outputs/m4_gru_loss
done
python scripts/summarize_gru_loss_strategies.py \
  reports/m4_gru_loss_seed_20260912.json reports/m4_gru_loss_seed_20260913.json \
  reports/m4_gru_loss_seed_20260914.json --output reports/m4_gru_loss_summary_2026-11-06.json
python scripts/score_rnn_strength.py --model-type gru --model outputs/m4_gru_loss/gru_seed_20260912.npz \
  --candidate-file /path/to/candidates.txt --output outputs/m4_gru_loss/candidate_scores.csv
python -m unittest discover -s tests -v
```
