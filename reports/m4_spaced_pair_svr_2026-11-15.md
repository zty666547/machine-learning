# M4：远距离碱基组合特征与 SVR 对照

## 目的与方法

已有位置特征编码每个位置上的单碱基和相邻双碱基。本轮保留这些特征，额外记录序列中相隔固定距离的两个碱基及其起始位置，尝试让 SVR 更容易利用远距离组合信息。例如，对间隔 10 的位置组合，同时记录序列第 1 位和第 11 位的碱基。

实验预先固定间隔为 10 和 17 bp；这些只是用于检验的间隔，**不是把样本判定为某类启动子，也不是经实验确认的 motif 或调控元件**。50 bp 序列分别有 40 和 33 个对应位置组合，每个位置组合有 16 种有序碱基对，共新增 1,168 维。原特征为 1,069 维，合计 2,237 维；仅用 A、C、G、T 的有效 50 bp 序列构建。

对照双方采用相同的外层相似性簇三折、训练样本、标签和 RBF SVR 超参数。新增特征后，标准化由每折训练部分拟合，`gamma=scale` 根据训练特征重新计算，因此核尺度也随输入维数变化；这是整套特征方案的比较，不能把差异完全归因于远距离组合信息。原 SVR 折外结果来自[既有记录](m4_svr_nested_calibration_2026-11-15.md)，输入、分折和模型配置摘要均经核对。规则见[预先固定的配置](../configs/m4_spaced_pair_svr_2026-11-15.toml)。

## 预测结果

| 训练集折外指标 | 原 SVR | 加入碱基组合特征 |
|---|---:|---:|
| 总体 MAE | 0.45760 | 0.46183 |
| Pearson | 0.24349 | 0.22195 |
| Spearman | 0.22766 | 0.20888 |
| 弱标签组 MAE | 0.47406 | 0.48425 |
| 中标签组 MAE | 0.18948 | 0.19002 |
| 强标签组 MAE | 0.71008 | 0.71208 |
| 预测值标准差 | 0.19231 | 0.18554 |

总体指标按 8,318 条折外预测计算，各标签组 MAE 为三折组内 MAE 的简单平均。每折用外层训练标签的三分位点确定分组边界，留出样本的组别在评价时根据其已有标签划分。标签标准差为 0.63657：两种模型的预测分布均明显窄于标签分布。本次固定配置下，新特征方案的总体 MAE 和相关性均未改善。

## 目标筛选结果

每折用该折训练部分的弱、中、强标签均值确定目标，在相同的留出池中按预测值离目标的距离选择前 50 条，再查看已有标签到目标的平均距离。下表为三折简单平均，单位是 log10 强度距离；该指标不是预测 MAE。

| 目标 | 原 SVR 选中记录的真实距离 | 加入特征后选中记录的真实距离 |
|---|---:|---:|
| 弱 | 0.3650 | 0.3793 |
| 中 | 0.3884 | 0.4066 |
| 强 | 0.7739 | 0.7311 |

强目标的平均筛选距离降低，但结果并非每折一致：三折原 SVR 分别为 0.6628、0.7503、0.9087，新增特征方案分别为 0.7169、0.7407、0.7358；第一折反而变差，第三折的变化对平均值影响较大。弱、中目标的平均筛选距离均上升。不能根据这一次训练内比较认定新特征稳定改善强目标筛选。

## 结论与边界

本轮的固定方案没有全面改善，**不替换现有预测器**。只试了两种预定间隔及一组模型配置，不能由此断定远距离特征整体无效。标准化、特征维数和核尺度均影响结果。此前多轮实验已使用这些训练数据开发模型；相似性簇三折只能减少该划分下的近似重复泄漏，不能把本次结果当作独立测试或生成序列的生物验证。验证集和测试集未参与本轮拟合或评价；课程测试集在更早开发中曾被查看。

新增编码通过位置、碱基顺序、间隔和非法输入单元测试，独立代码对 200 条训练序列逐位置核对编码；8,318 条折外记录及评价指标经独立核对，同环境重复运行的 JSON 与 CSV 一致，项目 58 项测试通过。完整结果和输入摘要见[JSON](m4_spaced_pair_svr_2026-11-15.json)；本地 `outputs/m4_spaced_pair_svr/oof_predictions.csv` 仅为已有训练样本的研究记录，按仓库规则不上传。

## 复现

安装 NumPy 2.5.4、scikit-learn 1.9.1 等依赖；先按[既有说明](m4_svr_nested_calibration_2026-11-15.md)生成原 SVR 折外记录。`DATA_DIR` 指向课程原始大肠杆菌数组目录：

```sh
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 VECLIB_MAXIMUM_THREADS=1 \
python scripts/evaluate_spaced_pair_svr.py --data-dir "$DATA_DIR" \
  --svr-oof outputs/m4_svr_nested_calibration/oof_predictions.csv \
  --output reports/m4_spaced_pair_svr_2026-11-15.json \
  --predictions outputs/m4_spaced_pair_svr/oof_predictions.csv
```
