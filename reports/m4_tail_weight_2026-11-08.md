# M4 强度预测器：强弱两端加权训练

## 本轮做了什么

上一轮诊断发现模型倾向把低强度样本预测得偏高、把高强度样本预测得偏低。本轮测试一种针对这一现象的训练目标：样本标签离训练目标均值越远，训练损失权重越高。模型结构、优化器、相似性分组折、随机种子和以验证 MAE 早停的规则保持与普通 RNN 相同。规则和权重在运行实验前固定，见[实验配置](../configs/m4_tail_weight_2026-11-08.toml)。

权重为 `1 + 0.75 × |标准化后的 log10 强度|`。标准化标签为 0 的样本权重为 1；绝对值越大，权重越高。损失除以当前小批次的平均权重，使整批梯度保持可比尺度。这个设置是一次事先固定的策略试验，不是调到验证集最优的配置。

## 结果

训练集按相似性簇进行固定三折，报告折外预测的三个种子均值 ± 总体标准差。MAE 越低越好；Pearson 衡量预测与真实数值的线性相关；Spearman 衡量高低排序的一致性；预测标准差比值显示预测范围相对于真实标签有多宽。

| 训练集折外指标 | 普通 RNN | 两端加权 RNN |
|---|---:|---:|
| MAE | 0.46343 ± 0.00257 | 0.47688 ± 0.00325 |
| Pearson | 0.16777 ± 0.00660 | 0.15560 ± 0.00974 |
| Spearman | 0.15197 ± 0.00838 | 0.14380 ± 0.00692 |
| 预测标准差 / 真实标准差 | 0.23923 ± 0.01909 | 0.27971 ± 0.02537 |
| 弱组 MAE | 0.47407 | 0.54274 |
| 中组 MAE | 0.16319 | 0.20027 |
| 强组 MAE | 0.75293 | 0.68753 |

加权后强组 MAE 平均下降约 0.065，但弱组误差增加约 0.069，中组也变差约 0.037。整体 MAE、Pearson 和 Spearman 均下降。弱组平均有符号误差从 +0.474 增至 +0.543，强组从 -0.750 变为 -0.676：模型减轻了强组低估，却更高估弱组。预测范围略变宽，但仍只有真实标签范围的约 28%。因此这是一个明确的取舍，不是整体性能改进。

开发验证集上，普通与加权 RNN 的 MAE 分别为 0.44294 ± 0.00362 和 0.46574 ± 0.00416；Pearson 分别为 0.19116 和 0.15013。开发验证集此前被多轮开发使用，这些数字不能视作独立测试结论。

## 如何解释

这次结果说明，仅仅提高“离平均强度较远”的样本权重，会让模型更努力拟合标签的高低端，但没有同时照顾好低端和高端。当前权重是按离均值的距离连续增加，不区分正负方向；本数据下它改善了强组低估，却使低组和中组更差。这可能表示高低两端需要分别处理，也可能只是本次设置不适合；本实验不能区分这两种解释。

## 数据边界与复现

训练集 8,318 条，开发验证集 1,783 条；训练集内固定相似性簇三折，分组边界由训练标签三分位数确定。普通 RNN 对照来自同一数据版本、相同折和种子的此前成对实验；每个结果文件都记录数据数组摘要值，并由脚本检查它们一致。测试数据仅由加载流程检查格式，本轮没有提取测试特征或计算测试指标；没有使用外部数据，也没有新增生成序列或湿实验评价。三个种子共用同一折分配，种子波动不是独立测试不确定性。

```sh
for seed in 20260912 20260913 20260914; do
  OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 VECLIB_MAXIMUM_THREADS=1 \
    python scripts/evaluate_tail_weight.py --data-dir "$DATA_DIR" --seed "$seed" \
    --output "reports/m4_tail_weight_seed_${seed}.json" --checkpoint-dir outputs/m4_tail_weight
done
python scripts/summarize_tail_weight.py
```

完整逐种子与分组指标见[汇总文件](m4_tail_weight_summary_2026-11-08.json)和三份种子 JSON。模型可用现有 `scripts/score_rnn_strength.py` 推理，分数仍是课程标签尺度上的预测 log10 强度，不是实测活性。本轮结果不足以替换现有融合筛选器。
