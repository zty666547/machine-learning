# M3：连续条件 VAE 响应分析

阶段记录日期：2026 年 9 月 20 日。使用 beta = 0.10 的连续条件 VAE，在训练集训练、验证集早停后，输入 7 个连续目标 `log10(强度)`：1.7、1.9、2.1、2.3、2.5、2.7、2.9；每个目标生成 500 条候选序列。

## 要回答的问题

VAE 的条件输入是连续数值，但“可以输入连续数字”不等于“生成结果会随数字平滑变化”。本实验只检查生成分布对连续条件的响应，不把当前强度预测器作为真实表达强度的证明。

## GC 响应

| 目标 log 强度 | 生成 GC 均值 |
|---:|---:|
| 1.7 | 0.4747 |
| 1.9 | 0.4690 |
| 2.1 | 0.4645 |
| 2.3 | 0.4669 |
| 2.5 | 0.4565 |
| 2.7 | 0.4515 |
| 2.9 | 0.4526 |

目标强度与生成 GC 均值的 Pearson 相关系数为 `-0.953`，线性斜率为 `-0.0195`。整体而言，目标强度升高时，生成 GC 倾向降低；这一方向与训练数据弱组 GC 较高、强组 GC 较低的现象一致。

相邻目标之间仍有局部波动，例如 2.1 到 2.3、2.7 到 2.9 时 GC 略有回升。因此，该模型已经显示出连续条件响应趋势，但尚不能称为严格单调、精确的连续强度控制。

## 随机种子复核

为避免将单次训练的随机结果误判为模型规律，使用三个随机种子重复完整训练与响应分析：

| 随机种子 | GC 响应斜率 | 目标强度与生成 GC 的 Pearson |
|---:|---:|---:|
| 20260912 | -0.0195 | -0.953 |
| 20260913 | -0.0118 | -0.887 |
| 20260914 | -0.0096 | -0.833 |

三个种子的相关系数均为负，平均为 `-0.891`，说明“目标强度升高、生成 GC 整体下降”的方向不是单次随机训练造成的偶然结果。

但不同种子在相同目标下的绝对 GC 均值存在差异，例如目标 1.7 的生成 GC 介于 0.4284 与 0.4942 之间。这说明当前 VAE 的训练稳定性仍有限，不能只依据单次训练给出精确的条件控制结论。原始汇总见 `m3_vae_response_seed_summary.json`。

## 序列分布变化

相邻目标的平均位置碱基 L1 差异为 0.084--0.094，3-mer JS 散度为 0.00050--0.00088。这表明改变连续目标不仅改变 GC 均值，也会使位置碱基组成和局部 k-mer 分布发生连续的小幅变化。

所有目标下生成序列均为合法、唯一且未直接复制训练序列。与全体训练集比较时，生成序列的 3-mer JS 散度约为 0.005--0.007，说明当前 VAE 的局部结构保真度仍低于条件自回归基线。

## 结论

连续条件 VAE 已经展示了可检测的条件响应：目标强度越高，生成 GC 总体越低，且序列组成会随目标连续变化。

当前证据只能说明“生成分布随条件变化”，不能证明真实表达强度随目标精确变化。下一轮优化应改善 VAE 的训练稳定性与局部 motif 保真度。
