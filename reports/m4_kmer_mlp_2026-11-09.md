# M4 序列特征 MLP 与线性岭回归配对比较

## 方法

此前位置 MLP 仅使用单碱基位置特征。本轮使用与树模型实验一致的特征：位置 1-mer、位置 2-mer、全局 1–3-mer 和 GC。比较两层 ReLU MLP 与线性岭回归，固定三个随机种子、相似性簇三折及模型参数；规则见[配置](../configs/m4_kmer_mlp_2026-11-09.toml)。

每折两种模型使用**相同的拟合样本**。MLP 额外使用训练折内早停集选择训练轮数；岭回归不使用该早停集拟合或选择参数。特征标准化和标签标准化均在拟合数据上确定。岭回归 alpha 固定为 1000，不使用开发验证集调参。

## 结果

训练集折外指标为三个种子的均值（岭回归在同一分折下是确定性的，三次结果相同）：

| 指标 | 线性岭回归 | 短片段特征 MLP |
|---|---:|---:|
| MAE | 0.47946 | 0.50750 |
| Pearson | 0.21669 | 0.14533 |
| Spearman | 0.19354 | 0.13584 |
| 弱组 MAE | 0.51363 | 0.53058 |
| 中组 MAE | 0.24710 | 0.28611 |
| 强组 MAE | 0.67755 | 0.70573 |
| 预测标准差 / 标签标准差 | 0.42226 | 0.50249 |

MLP 的预测范围更宽，但总体及各组 MAE 均更大，相关性也更低；范围更宽并不等于更准确。三个 MLP 的折外 MAE 分别为 0.50467、0.51432、0.50352，均高于线性模型的 0.47946。九个外层训练过程均运行 22 轮后结束，提示在该固定配置下早停较早；这本身不能证明过拟合的具体原因。

开发验证 MAE 分别为 0.45997 和 0.48337；开发验证集已反复用于开发，不是独立评价。这次仅检验一种 MLP 配置，不能据此否定所有非线性模型或特征组合，也不替换现有融合筛选器。

## 边界与复现

训练集 8,318 条、开发验证集 1,783 条；组边界来自训练标签三分位数。三个种子共用外层折，不是独立测试；岭回归没有使用早停集，而 MLP 使用早停标签选轮数。测试数组仅由加载器检查格式，不用于提取特征和计算指标。本轮没有新的外部数据或湿实验，未导出推理检查点。


固定种子 20260912 的完整实验在本机重新运行后 JSON 逐字节一致；跨数值环境可能有差异。各 JSON 保存数据摘要、分折训练数量和完整分组指标。
