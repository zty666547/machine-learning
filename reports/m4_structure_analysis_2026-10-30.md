# M4 生成序列的位置结构分析

## 1. 本轮目的和结论

在相同强度条件和每组采样数量下，比较连续条件自回归与连续条件 VAE 生成序列的局部结构，检查它们与大肠杆菌训练数据的位置分布有多接近。结果表明：**当前实验设置下，自回归生成序列在逐位置碱基、3-mer 和 5-mer 分布上均比 VAE 更接近训练数据**；三组条件分别计算时，结果方向一致。

这说明当前自回归实现较好地复现了训练数据的局部分布，并不能据此断言它具有更好的真实启动子功能，也不能推断模型在独立数据上的泛化能力。本轮是结构诊断，没有评估实际表达强度或生物学功能。

## 2. 数据与实验设置

- 使用已固定的 8,318 条大肠杆菌训练序列，按训练集强度三等分为弱、中、强，分别有 2,773、2,772、2,773 条。序列长度均为 50 bp。每组目标值取该组训练数据对数强度的均值，约为 1.7150、2.1410、2.9896。
- 两个模型都在同一个训练集上拟合。连续条件自回归采用 3 阶上下文与 3 个条件分箱；连续条件 VAE 的隐藏层维度为 128、潜变量维度为 16、KL 权重为 0.2，最多训练 120 轮。本轮三个 VAE 实例均运行至第 120 轮。
- VAE 训练过程使用已有验证集进行早停；因此验证集属于开发过程的一部分，并非独立最终评价。本轮没有计算或使用测试集指标。
- 每次实验对每个条件、每个生成器各采样 500 条序列；共重复三次。模型随机种子为 20260912、20260913、20260914，采样种子为 20261030、20261130、20261230。自回归拟合本身是确定性的，其三次差异来自采样；VAE 的差异同时包含训练和采样随机性。数据文件和划分文件的 SHA-256 保存在结果 JSON 中。
- 每组生成样本与该组全部训练序列比较。另从同组训练数据中无放回抽取 500 条，与未抽中的训练序列比较，作为真实样本有限采样差异的参考。**这两种对照的参照集合大小和组成不同，不能直接据此认定生成器比真实序列更好。**
- 对抽中的真实序列逐条打乱碱基顺序，保留每条序列的碱基组成和 GC 含量，但破坏原有位置与局部顺序，作为描述性的破坏对照，并非显著性检验。

## 3. 如何理解指标

1. **位置碱基 L1 距离**：分别统计第 1 至 50 位上 A、C、G、T 的频率，计算样本与参考组的四项频率绝对差之和，再对 50 个位置取平均。越小代表逐位置单碱基分布越接近。
2. **逐位置 k-mer JS 散度**：在每个起始位置分别统计长度为 k 的连续片段的频率分布，计算与参考数据的 Jensen–Shannon 散度，最后对所有起始位置取平均。这里使用自然对数，数值越小代表该位置局部片段分布越接近。
3. **与过去的 3-mer 指标的区别**：本轮先按位置分别比较，再对位置取平均；以前的全局 3-mer 指标是把不同位置的片段合并统计。两者回答的问题不同，数值不能直接比较。
4. 5-mer 有 1,024 种可能组合，每个条件仅有 500 条生成样本，因此逐位置频率存在明显稀疏性与抽样噪声；3-mer 和 5-mer 的散度数值也不宜直接比较。GC 只描述整体碱基组成，不能单独证明序列结构相似。

## 4. 三次实验、三组条件的总体均值

下表把每个条件、每次实验的结果等权平均。距离或散度越小，表示在本轮对应的参照集合下越接近；不同参照集合的行需要结合第 2 节理解。

| 样本及参照 | 位置碱基 L1 | 逐位置 3-mer JS | 逐位置 5-mer JS | 平均 GC |
| --- | ---: | ---: | ---: | ---: |
| 真实样本 vs 同组剩余训练样本 | 0.06805 | 0.02045 | 0.27322 | 0.44232 |
| 打乱后的真实样本 vs 同组剩余训练样本 | 0.18253 | 0.05375 | 0.35853 | 0.44232 |
| 自回归 vs 同组完整训练数据 | 0.06030 | 0.01705 | 0.24575 | 0.44136 |
| VAE vs 同组完整训练数据 | 0.11990 | 0.03180 | 0.29898 | 0.44617 |

打乱前后 GC 相同，但位置与片段差异上升，说明只看 GC 会漏掉顺序信息。该对照不代表随机序列的全部可能形式，也不提供统计显著性结论。

分条件看，自回归的逐位置 3-mer 散度均值分别为弱 0.01662、中 0.01729、强 0.01723；VAE 分别为 0.03238、0.03173、0.03128。完整的每次实验结果、每个位置的 A/C/G/T 频率和训练组常见 3-mer、5-mer 的逐位频率保存在 JSON 中；频率也可导出 CSV 供复核或绘图。

## 5. −35/−10 候选序列：探索性扫描

文献支持该数据集使用 TSS 上游 50 bp 序列，但不能仅凭这一信息确认每条序列的坐标、方向与 σ 因子注释均满足同一假设。仅为探索，我们假设 50 位按 5′→3′ 对应 TSS 的 −50 至 −1，将大肠杆菌 σ70 常见的 −35 共识 `TTGACA` 放在起点 −35，将 −10 共识 `TATAAT` 放在起点 −12。这是**分析假设**，不是对所有样本的已确认注释。参见 [数据来源核验](m4_ecoli_provenance_2026-10-29.md) 和 [σ70 启动子元件研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC3209215/)。

主扫描允许起点在各假定位置前后移动 1 bp，且六个碱基中最多有 1 个错配；两窗口各至少有一次命中时记作“双窗口命中”，不额外约束两处序列间距。对完整训练组与各次生成结果应用相同规则：

| 条件 | 训练组 −35 / −10 / 双窗口命中率 | 自回归三次均值 | VAE 三次均值 |
| --- | --- | --- | --- |
| 弱 | 5.08% / 26.72% / 0.40% | 5.73% / 23.33% / 0.87% | 3.00% / 22.80% / 0.60% |
| 中 | 5.16% / 29.00% / 0.58% | 5.80% / 22.33% / 1.47% | 2.20% / 20.33% / 0.53% |
| 强 | 7.83% / 29.93% / 1.33% | 8.73% / 23.00% / 2.47% | 4.40% / 22.20% / 0.60% |

窗口范围会改变结果：例如，强组训练数据的双窗口命中率在起点容许范围从 ±1 bp 扩大到 ±5 bp 后，由 1.33% 变为约 3.68%。结果 JSON 还保存了两个窗口同时向前或向后移动 5 bp 的对照。数字受共识序列、错配限制与窗口假设影响；**命中不是功能验证，未命中也不等于没有启动子功能**。不同 σ 因子可能识别不同序列，短共识及固定窗口不能覆盖所有真实启动子。

逐位置频率还可用于查看更具体的片段。例如，训练组的 `ATAAT` 在序列第 40 位起始处的频率分别为弱 6.02%、中 4.44%、强 4.22%。这只是一个位置上的 5-mer 频率示例，不能单独证明 −10 元件存在或发挥功能。

## 6. 复现与结果文件

在仓库根目录、安装项目所需依赖后运行；`DATA_DIR` 指向包含 `promoter.npy` 与 `gene_expression.npy` 的课程数据目录。限制数值库线程数有助于在相同环境下复现。

```bash
DATA_DIR="/path/to/course_raw/promoter/strenth/data"
export OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 VECLIB_MAXIMUM_THREADS=1
python scripts/evaluate_m4_structure.py --data-dir "$DATA_DIR" --vae-seed 20260912 --sample-seed 20261030 --output reports/m4_structure_seed_20260912.json
python scripts/evaluate_m4_structure.py --data-dir "$DATA_DIR" --vae-seed 20260913 --sample-seed 20261130 --output reports/m4_structure_seed_20260913.json
python scripts/evaluate_m4_structure.py --data-dir "$DATA_DIR" --vae-seed 20260914 --sample-seed 20261230 --output reports/m4_structure_seed_20260914.json
python scripts/summarize_m4_structure.py reports/m4_structure_seed_20260912.json reports/m4_structure_seed_20260913.json reports/m4_structure_seed_20260914.json --output reports/m4_structure_summary_2026-10-30.json
python scripts/export_m4_structure_profiles.py --summary reports/m4_structure_summary_2026-10-30.json --output outputs/m4_structure/position_profiles.csv
```

三个单次结果和汇总 JSON 均已纳入仓库，CSV 是可按上述命令重新生成的派生文件。CSV 的位置从 1 开始，TSS 相对坐标列只适用于前述 −50 至 −1 假设。每组只导出训练组总体最常见的 5 个 3-mer 和 5 个 5-mer 的逐位频率，它们不自动等同于 motif。

## 7. 后续工作

- 优先核查逐序列 TSS、方向及 σ 因子信息；如果无法确认，在后续展示中继续保留候选扫描的假设和限制。
- 在不反复使用测试集选模型的前提下，进一步研究弱、中、强目标下的结构和预测强度响应，明确评估器误差对结论的影响。
- 如需验证序列是否真正具有启动子活性，需要独立可靠的实验或其他有明确适用范围的证据；本轮结构结果不能替代该验证。
