# M4：将三个 CNN 集成接入融合筛选器的配对比较

## 方法

上一轮三个 CNN 的等权平均优于单个 CNN 的折外结果。本轮检查它是否也能改善现有融合方案：固定原有 CNN、全局 k-mer 岭回归、位置岭回归权重 0.5 / 0.4 / 0.1 和岭回归 alpha=10；只将 CNN 一项从种子 20260912 的预测换成三个既有种子的等权平均。所有评分均在 log10 强度尺度上，选择规则在结果前固定，见[配置](../configs/m4_fusion_cnn_ensemble_2026-11-09.toml)。

固定相似性簇三折，三份 CNN 折外预测来自相同外层折、训练折内部早停；两个岭回归每折使用该折外层拟合集（含 CNN 的早停部分）。两种融合方式共享同一份岭回归预测和全部样本。CNN 成员预测复核数据摘要、分折、NumPy 版本、种子，以及此前折外和开发验证 MAE；岭回归本轮重新训练。对照是同样训练内早停的单 CNN 融合，不是原部署 M3 中用开发验证集早停的完整复跑。

## 训练集折外结果

| 指标 | 单 CNN 融合 | 三 CNN 集成融合 |
|---|---:|---:|
| MAE | 0.45725 | 0.45710 |
| Pearson | 0.24992 | 0.25177 |
| Spearman | 0.22719 | 0.23188 |
| 弱组 MAE | 0.49511 | 0.49796 |
| 中组 MAE | 0.16799 | 0.16617 |
| 强组 MAE | 0.70854 | 0.70705 |
| 预测标准差 / 标签标准差 | 0.23092 | 0.22123 |

两种方式的折外 MAE 差约 0.00015；集成 Spearman 略高，但弱组 MAE 略高，预测范围进一步收缩。约 49.6% 的折外样本绝对误差下降；这只是描述性比例，不代表统计显著性或独立泛化。

开发验证集中，单 CNN 融合与集成融合的 MAE 分别为 0.43060 和 0.43229，Spearman 为 0.24540 和 0.25483。开发验证集已反复使用；本轮没有用它选择权重或模型。验证表现存在取舍，不能作为独立证据。

## 结论与边界

本次固定规则下，CNN 集成放入融合器后的总体误差收益非常小，排序略有改善，但弱组和范围收缩仍然存在。现有结果不足以替换 M3 固定筛选器。

训练集 8,318 条、开发验证集 1,783 条；组边界按训练标签三分位数确定。三个 CNN 使用相同样本和分折，不是独立测试。早期课程测试集曾被查看；本轮只通过加载器检查全部数据格式，未提取测试特征或计算测试指标。无外部评价和湿实验，也不证明生成序列的真实活性。

## 复现

先按 [CNN 集成记录](m4_cnn_ensemble_2026-11-09.md)重新生成三个 `member_*.npz`，再运行：

```sh
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 VECLIB_MAXIMUM_THREADS=1 \
 python scripts/evaluate_fusion_cnn_ensemble.py --data-dir "$DATA_DIR" \
 --members-dir outputs/m4_cnn_ensemble \
 --output reports/m4_fusion_cnn_ensemble_2026-11-09.json
```

本机基于同一输入重复运行的汇总 JSON 逐字节一致；不同数值环境可能产生差异。完整分组误差和成员文件摘要见[结果文件](m4_fusion_cnn_ensemble_2026-11-09.json)。
