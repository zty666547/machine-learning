# M4 融合筛选器中替换 SVR 分量的配对比较

## 方法

上一轮 RBF SVR 相对位置特征岭回归改善了总体和弱组误差，但强组更差。本轮固定现有融合系数 0.5 / 0.4 / 0.1，比较：

- 原分量：0.5 × CNN + 0.4 × 全局 k-mer 岭回归 + 0.1 × 位置岭回归；
- 替换方案：0.5 × 同一个 CNN + 0.4 × RBF SVR + 0.1 × 同一个位置岭回归。

注意：替换分量同时改变模型和特征。原全局岭回归使用全局 1–3-mer 与 GC；SVR 使用位置 1-mer/2-mer、全局 1–3-mer 和 GC。不能仅将变化归因于 RBF 算法。权重、分折、SVR 参数和比较规则在结果前固定，见[配置](../configs/m4_fusion_svr_2026-11-09.toml)和[SVR 原配置](../configs/m4_rbf_svr_2026-11-09.toml)。

训练集相似性簇三折，复用种子 20260912 的同折 CNN 折外预测；两个岭回归和 SVR 都使用相同外层训练数据（含 CNN 的早停部分），SVR 标准化和 gamma 每折只在训练折计算。两个融合方案共享同一 CNN 与位置岭回归预测。CNN 成员的数据、种子、分折、原环境版本和此前总体 MAE 均做核验；SVR 重新计算并复现上一轮总体 MAE。与先前训练内早停的单 CNN 融合实验相比，本轮基线折外和开发验证 MAE 一致。

## 结果

| 训练集折外指标 | 原分量融合 | SVR 替换全局岭回归 |
|---|---:|---:|
| MAE | 0.45725 | 0.45387 |
| Pearson | 0.24992 | 0.25980 |
| Spearman | 0.22719 | 0.23700 |
| 弱组 MAE | 0.49511 | 0.46974 |
| 中组 MAE | 0.16799 | 0.16995 |
| 强组 MAE | 0.70854 | 0.72181 |
| 预测标准差 / 标签标准差 | 0.23092 | 0.25578 |

折外总体 MAE 与弱组 MAE 降低，排序相关性略有提高；强组 MAE 上升，强组平均有符号误差由 -0.70515 变为 -0.71818。约 51.8% 的折外样本绝对误差降低，这是描述性比例，并非统计显著性结论。

开发验证集 MAE 为 0.43060 和 0.42927，Pearson 为 0.27135 和 0.26700；弱组 MAE 为 0.44803 和 0.42801，强组为 0.69105 和 0.70388。开发验证集已多轮使用，不是独立证据；本轮没有根据该数据选权重或模型。

## 边界与结论

本次 CNN 采用训练集内部早停，不是原 M3 用开发验证集早停的完整部署流程；本轮配对对照不能直接替代原 M3 的历史指标。SVR 与全局岭回归的特征不同，且仅检验一套固定分折与参数。折外结果有积极信号，但强组低估加重，不能认定整体可靠改进；现有 M3 融合筛选器不变，候选方法未导出推理检查点。

训练集 8,318 条、开发验证 1,783 条；强弱组边界按训练标签三分位数确定。测试数据仅由加载器检查格式，未提取测试特征或计算指标；课程测试集早期曾被查看。无外部数据评价或湿实验，不证明生成序列真实活性。

## 复现

先按 [CNN 集成实验](m4_cnn_ensemble_2026-11-09.md)生成成员预测文件，安装 NumPy 2.5.4 和 scikit-learn 1.9.1，再执行：

```sh
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 VECLIB_MAXIMUM_THREADS=1 \
 python scripts/evaluate_fusion_svr.py --data-dir "$DATA_DIR" \
 --cnn-member outputs/m4_cnn_ensemble/member_20260912.npz \
 --output reports/m4_fusion_svr_2026-11-09.json
```

CNN 成员文件为此前 NumPy 2.3.5 环境生成，其元数据和指标与原记录核对；SVR/岭回归本轮使用 NumPy 2.5.4 和 scikit-learn 1.9.1。模型输入数组摘要、环境版本与完整组内结果见[结果文件](m4_fusion_svr_2026-11-09.json)。跨环境数值可能不同。
