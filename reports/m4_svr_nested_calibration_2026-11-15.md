# M4：SVR 嵌套折外校准实验

## 目的和方法

上一轮目标筛选发现，预测值接近目标并不保证实际标签接近。本轮尝试给已有位置特征 RBF SVR 增加一层线性校准，检查它能否同时改善强度预测和按目标筛选。

校准关系写作 `校准预测值 = 截距 + 斜率 × 原始预测值`。在每个外层训练部分内部，再按相似性簇分成两折；每条内层训练记录的预测由没有使用该记录所属簇的模型给出。用这些内层折外预测及其已知标签，通过最小二乘确定截距和斜率。随后在整个外层训练部分重训 SVR，将校准层应用于外层留出部分的预测。三折分别进行；SVR 参数和特征与原实验一致。模型、分折和规则在运行前固定，见[配置](../configs/m4_svr_nested_calibration_2026-11-15.toml)。

本次校准只使用外层训练数据，不读取外层留出标签；对照是在同一批样本上比较同一个外层 SVR 校准前后的结果。内层 SVR 的训练规模约为外层最终 SVR 的一半，校准关系可能受训练规模差异影响。

## 强度预测结果

| 指标 | 原始 SVR | 加校准层 |
|---|---:|---:|
| 总体折外 MAE | 0.45760 | 0.46353 |
| Pearson | 0.24349 | 0.24162 |
| Spearman | 0.22766 | 0.22716 |
| 弱标签组 MAE | 0.47406 | 0.53389 |
| 中标签组 MAE | 0.18948 | 0.18275 |
| 强标签组 MAE | 0.71008 | 0.67475 |

总体 MAE 按全部 8,318 条记录计算；各标签组 MAE 为各折组内 MAE 的简单平均，组别根据相应外层训练数据的三分位点，在评价时用留出样本已有标签回顾划定。三折校准斜率分别为 0.639、0.768、0.702。这一校准后总体误差和弱组误差增大，中、强标签组的平均 MAE 降低；不能仅凭其中某一组的变化宣布整体改进。

## 目标筛选结果

沿用上一轮规则：每折弱、中、强目标由外层训练标签各组的均值确定，两个方案在同一整折候选池中分别选预测值最接近目标的 50 条，再计算它们已有标签到目标的平均距离。表中是三折简单平均，单位为 log10 强度距离；它不是预测 MAE。

| 目标 | 原始 SVR 选择的真实距离 | 校准后选择的真实距离 |
|---|---:|---:|
| 弱 | 0.3650 | 0.3682 |
| 中 | 0.3884 | 0.3704 |
| 强 | 0.7739 | 0.7739 |

中目标的平均筛选距离有所下降，弱目标略有上升。强目标三折中校准前后的前 50 条完全相同，因此真实距离也完全相同。校准改变分数刻度，但不一定改变排序或选出的序列。观察到的中目标改善来自同一训练数据内的探索性对照，尚不能认定对新数据稳定有效。

## 结论和边界

该方案没有取得一致改善：**暂不替换当前预测器，也不把它当作已验证的升级方案**。此前模型结构及参数已经在项目数据上经过开发和比较，此次虽在每个外折隔离相似性簇，仍是训练集内的探索性评价，不是全新独立测试，也不是生成序列的生物实验验证。本轮没有用开发验证集或测试集进行新的模型拟合和评价；课程测试集曾在更早开发中被查看。

重新拟合的未校准 SVR 对三个目标筛选的每折结果与上一轮记录一致；独立代码核对了全部折外预测的样本归属、已有标签、校准关系、MAE、目标及筛选差距。重复运行的折外预测和原有指标完全一致；项目现有 55 项测试通过。输出记录及摘要见[JSON](m4_svr_nested_calibration_2026-11-15.json)；本地 `outputs/m4_svr_nested_calibration/oof_predictions.csv` 是已有训练样本的研究记录，按仓库规则不上传。

## 复现

在 NumPy 2.5.4、scikit-learn 1.9.1 环境下，`DATA_DIR` 指向课程原始大肠杆菌序列和标签数组所在目录：

```sh
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 VECLIB_MAXIMUM_THREADS=1 \
python scripts/evaluate_svr_nested_calibration.py --data-dir "$DATA_DIR" \
  --output reports/m4_svr_nested_calibration_2026-11-15.json \
  --predictions outputs/m4_svr_nested_calibration/oof_predictions.csv
```
