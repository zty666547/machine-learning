# M4 强度预测器：弱、中、强分组加权

为进一步检查端点加权造成的取舍，在每个训练折内部按拟合样本标签的三分位数分成弱、中、强组，弱组和强组各赋权 1.5，中组赋权 1.0；权重在小批次内按均值归一化。分组边界仅由拟合样本计算，整体结构、早停、种子和相似性分折与普通 RNN 保持一致。参数见[配置](../configs/m4_balanced_group_2026-11-08.toml)。

训练集内部三折折外指标，三个种子均值：

| 指标 | 普通 RNN | 分组加权 RNN |
|---|---:|---:|
| MAE | 0.46343 | 0.46439 |
| Pearson | 0.16777 | 0.16586 |
| Spearman | 0.15197 | 0.15598 |
| 弱组 MAE | 0.47407 | 0.48514 |
| 中组 MAE | 0.16319 | 0.16618 |
| 强组 MAE | 0.75293 | 0.74174 |

强组误差稍降，但弱组误差上升，总体 MAE 略升，Spearman 略升。该配置没有同时改善强弱两端。预测标准差与真实标准差之比从 0.23923 变为 0.23637，预测范围依然偏窄。开发验证 MAE 从 0.44294 变为 0.44405；该验证集已重复用于开发，不是独立评价。

本轮固定训练集 8,318 条、开发验证集 1,783 条；三种子共用外层分折，不是三个独立测试集。测试数据仅由数据加载器检查格式，本轮未提取测试特征或计算测试指标。无新外部数据评价或湿实验。完整分组指标和运行参数见三份 `m4_balanced_group_seed_*.json` 和 `scripts/evaluate_balanced_group.py`。普通 RNN 基线引用同数据、折和种子的既有实验结果。结果不足以更换现有融合筛选器。
