# M4：生成器强弱目标的 GC 匹配对照

## 为什么做这个检查

已有结果显示，连续自回归和连续条件 VAE 在弱、中、强目标下生成的序列，其预测强度均分随目标升高而上升；同时，各组的平均 GC 含量发生变化。本轮检查：当弱、强组选出的序列具有完全相同的 GC 数量分布时，这一预测分数差异是否仍然存在。

本轮复用已观察过的三个运行、两种生成器和弱、强两组生成序列；每种生成器、每次运行、每个目标原有 500 条，没有重新训练模型或生成新序列。由于之前已经看到分数与 GC 的总体趋势，本轮属于**事后探索性分析**。

## 方法

在同一生成器和运行内，按每条 50 bp 序列的 G+C 碱基总数（0–50）分层。每个 GC 数量层中，若弱组有 `a` 条、强组有 `b` 条，则两边各随机抽取 `min(a,b)` 条；随机数种子预先固定，抽样不使用预测分数。这样匹配后的弱、强组在每个 GC 数量上的序列数完全相同，并在此规则下保留尽可能多的序列。该过程匹配的是两组分布，不代表序列之间存在生物学配对关系。

分别计算 M3 融合筛选器与 SVR 的 `强目标组预测均分 − 弱目标组预测均分`，比较匹配前和匹配后的差值。结果不是强度误差，也不是单条序列的实测值。三个运行的均值采用简单平均；各运行共享训练数据，不是独立数据集。规则见[预先固定的配置](../configs/m4_generated_gc_matching_2026-11-16.toml)，输入 CSV 的 SHA-256 和原有组均分均经过核对。

## 结果

下表分数差以预测 log10 强度为单位，数值为三个运行的简单平均。正数表示强目标组的预测均分高于弱目标组。

| 生成器 | 评分器 | 匹配前强减弱 | GC 匹配后强减弱 | 每运行每组保留数量 |
|---|---|---:|---:|---|
| 连续自回归 | M3 | 0.1058 | 0.0853 | 429、418、418 / 500 |
| 连续自回归 | SVR | 0.1939 | 0.1784 | 429、418、418 / 500 |
| 连续 VAE | M3 | 0.0509 | 0.0328 | 423、426、423 / 500 |
| 连续 VAE | SVR | 0.0609 | 0.0430 | 423、426、423 / 500 |

两种生成器、两个评分器在全部三个运行中，GC 匹配后的差值均为正。逐次结果如下：

| 生成器 | 评分器 | 运行 20260912 | 运行 20260913 | 运行 20260914 |
|---|---|---:|---:|---:|
| 连续自回归 | M3 | 0.0872 | 0.0877 | 0.0809 |
| 连续自回归 | SVR | 0.1856 | 0.1759 | 0.1736 |
| 连续 VAE | M3 | 0.0179 | 0.0341 | 0.0464 |
| 连续 VAE | SVR | 0.0298 | 0.0411 | 0.0582 |

在这些保留下来的候选中，即使弱、强组的整体 GC 数量分布相同，两个评分器仍给强目标组更高的平均分。该观察说明评分差异**不只是两组 GC 总量分布不同这一种简单现象**；但分数差下降的幅度不能解释为 GC 的因果贡献，也不能据此计算真实强度变化。

## 边界

GC 总数相同不代表 GC 在序列中的位置、其他 k-mer、motif、序列相似度或其他特征相同；评分器可能利用这些特征及其与 GC 的交互。匹配改变了被分析的样本，且每个 GC 层内随机抽样只固定一组种子，没有系统测试不同抽样带来的波动。保留约 84%–86% 的弱组与强组序列，结论只描述这批样本和固定规则，不能外推到未匹配的所有序列。

M3 和 SVR 与生成器共享项目训练数据，二者也不是相互独立的生物实验验证。生成序列没有对应的实测强度；因此不能据此证明生成器准确控制强度、能够真实表达或优于其他模型。本轮未使用测试集进行新的评价，也没有新增外部数据；课程测试集在更早的开发中曾被查看。

独立代码核对了 5,074 条保留记录的来源、GC 数量、每层最大匹配数和预测分数差；同环境重复运行 JSON 和 CSV 完全一致，项目 58 项现有测试通过。逐运行及分层结果见[JSON](m4_generated_gc_matching_2026-11-16.json)；`outputs/m4_generated_gc_matching/selected_indices.csv` 是本地研究索引，按仓库规则不上传，不是最终实验候选名单。

## 复现

先按[既有记录](m4_target_repeat_2026-11-13.md)生成校验摘要一致的 `outputs/m4_target_repeats/rankings_all.csv`。在与 JSON 记录一致的 NumPy 环境运行：

```sh
python scripts/analyze_generated_gc_matching.py \
  --ranking-csv outputs/m4_target_repeats/rankings_all.csv \
  --output reports/m4_generated_gc_matching_2026-11-16.json \
  --selected-csv outputs/m4_generated_gc_matching/selected_indices.csv
```
