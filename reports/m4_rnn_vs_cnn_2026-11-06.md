# M4：基础 RNN 与 motif CNN 的强度预测对照

日期：2026-11-06。本轮按固定方案实现普通 RNN，并与已有 motif CNN 在相同相似性簇划分下比较启动子强度预测。这里的 RNN 是**强度预测器候选**，不是用来替换连续自回归生成器的生成模型。

## 1. 主要结论

本轮固定配置下，RNN 可以完成训练、保存、加载和 50 bp 候选打分，但其总体效果没有超过同条件下的 CNN：三个随机种子的训练集折外 MAE 均值，RNN 为 **0.46343**，CNN 为 **0.46050**；开发验证集均值分别为 **0.44294** 和 **0.43718**。

开发验证集中，RNN 的强组 MAE 均值较低（0.70568 对 0.73053），弱组 MAE 均值较高（0.45423 对 0.41910）。该数据集已多次参与开发，且三个种子共用同一批数据和分折；不能把这一现象当作独立泛化保证或显著性结论。当前**不替换已有融合筛选器**。

这次只测试了一个普通 RNN 配置，不能推出所有 RNN、LSTM 或 GRU 都比 CNN 差。

## 2. 模型与实验设置

- 使用固定的大肠杆菌 50 bp 数据：训练 8,318 条，开发验证 1,783 条；标签使用 `log10(课程强度)`。原数组读取时会进行完整格式检查，但测试记录不参与特征构造、拟合、选择或指标计算。测试集在更早期曾被查看，不是从未接触的最终测试集。
- RNN 使用单向、单层、32 维隐藏状态和 `tanh`，从第一个碱基依次读取到最后一个碱基。把 50 个隐藏状态按 5 个位置区间分别取均值，接 64 单元预测头输出连续强度。参数量为 **11,553**。
- CNN 沿用 7 bp 卷积、32 个卷积核、5 个位置区间和 64 单元预测头，参数量为 **11,297**。两者参数规模接近但不完全相同；CNN 的 5 区间来自 44 个卷积窗口，RNN 的 5 区间来自 50 个隐藏状态，也不是完全相同的位置表示。
- 两个模型均使用训练子集的目标均值和标准差归一化、相同批大小、学习率、权重衰减、最多 150 轮和按早停子集 MAE 选择检查点。RNN 另使用全局梯度范数裁剪 1.0，防止训练不稳定；因此本次不是只改变网络层而其他所有内部训练行为完全相同的因果消融。
- 按相似性簇做**训练集内部三折交叉预测**；每个外层训练部分再按簇拆出约 20% 做早停，保证同簇不跨相应分组。每次完整实验使用 20260912、20260913、20260914 三个模型随机种子，所有种子共用同一组分折。开发验证集不参与本轮早停或选型，但它在项目此前已多次用于开发。
- 每个最终比较模型使用训练集内部同一份约 80% 拟合、约 20% 早停，并在开发验证集计算指标。它不同于 M3 融合预测器使用的完整训练方式，因此不应直接把本轮单模型结果与融合模型当作严格配对实验。

## 3. 整体结果

表中为三个模型种子的均值 ± 总体标准差；三次不是独立数据集重复。MAE 和 RMSE 的单位均为 `log10(课程强度)`。

| 数据与模型 | MAE ↓ | RMSE ↓ | Pearson ↑ | Spearman ↑ |
| --- | ---: | ---: | ---: | ---: |
| 训练折外 CNN | 0.46050 ± 0.00077 | 0.62907 ± 0.00166 | 0.19842 ± 0.00684 | 0.17743 ± 0.00471 |
| 训练折外 RNN | 0.46343 ± 0.00257 | 0.63333 ± 0.00061 | 0.16777 ± 0.00660 | 0.15197 ± 0.00838 |
| 开发验证 CNN | 0.43718 ± 0.00123 | 0.59282 ± 0.00362 | 0.22246 ± 0.00557 | 0.19249 ± 0.00283 |
| 开发验证 RNN | 0.44294 ± 0.00362 | 0.59417 ± 0.00359 | 0.19116 ± 0.01111 | 0.17423 ± 0.01543 |

三个种子中，训练折外 RNN MAE 均高于对应 CNN，均值差约 +0.00293；开发验证集均值差约 +0.00576。差异幅度不大，模型结构、表示方式及裁剪规则均不同；不把差异归因于某一个机制，也不声称统计显著。

每次重跑的 CNN 训练折外和开发验证 MAE 都与先前相同种子、相同分折的 5 区间记录一致，作为配置回归检查。

## 4. 强弱组与预测范围

使用训练集三等分边界，并按开发验证数据的**真实标签**回顾分组：

| 方法 | 弱组 MAE | 中组 MAE | 强组 MAE | 弱组平均误差 | 强组平均误差 |
| --- | ---: | ---: | ---: | ---: | ---: |
| CNN | 0.41910 | 0.16755 | 0.73053 | +0.41775 | −0.72577 |
| RNN | 0.45423 | 0.17559 | 0.70568 | +0.45335 | −0.69706 |

平均误差定义为预测减真实值。两种模型都表现出弱组高估、强组低估；RNN 在此组数据中强端低估略轻，但弱端高估更明显。开发验证集上预测标准差与真实标签标准差之比分别约为 CNN 0.28656、RNN 0.29372，预测范围仍明显收缩。**这不证明 RNN 已解决强度控制问题**。

## 5. 实现、检查与复现

新增 [RNN 模型](../src/promoter_ml/models/rnn_strength.py)，使用时间展开反向传播、梯度裁剪、按开发早停子集 MAE 保存最佳参数，并支持 `.npz` 保存和加载；新增 [候选打分入口](../scripts/score_rnn_strength.py)。

单元测试用有限差分核验多个参数的梯度，用合成任务检查学习能力，并核对模型保存/加载及打分脚本。三个种子分别跑完整配对实验；种子 20260912 重新运行后，实验 JSON 与检查点各数组一致。三个检查点是**本轮训练内 80% 拟合 + 20% 早停的实验模型**，不是重新训练的最终生产模型；它们保存在本地 `outputs/m4_rnn/`，不会作为最终筛选器自动替换或提交 Git。

```bash
export OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 VECLIB_MAXIMUM_THREADS=1
for seed in 20260912 20260913 20260914; do
  python scripts/evaluate_rnn_vs_cnn.py \
    --data-dir /path/to/promoter/strenth/data --seed "$seed" \
    --output "reports/m4_rnn_vs_cnn_seed_${seed}.json" \
    --model-output "outputs/m4_rnn/model_seed_${seed}.npz"
done
python scripts/summarize_rnn_vs_cnn.py \
  reports/m4_rnn_vs_cnn_seed_20260912.json reports/m4_rnn_vs_cnn_seed_20260913.json \
  reports/m4_rnn_vs_cnn_seed_20260914.json --output reports/m4_rnn_vs_cnn_summary_2026-11-06.json
python scripts/score_rnn_strength.py --model outputs/m4_rnn/model_seed_20260912.npz \
  --candidate-file /path/to/candidates.txt --output outputs/m4_rnn/candidate_scores.csv
python -m unittest discover -s tests -v
```

原始指标：[20260912](m4_rnn_vs_cnn_seed_20260912.json)、[20260913](m4_rnn_vs_cnn_seed_20260913.json)、[20260914](m4_rnn_vs_cnn_seed_20260914.json)、[汇总](m4_rnn_vs_cnn_summary_2026-11-06.json)。模型输入文件每行一条 50 bp A/C/G/T 序列；输出是预测的对数强度，不是实验测量。

如果下一步比较 LSTM 或 GRU，应预先固定其参数规模、相同簇划分和早停策略，避免用多轮开发验证集结果直接反复选模型；还应优先分析输出收缩和强弱组误差。
