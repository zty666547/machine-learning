# M4：生成器条件响应与强度筛选分数诊断

## 1. 目的与主要结论

在上一轮位置结构分析的基础上，使用现有 M3 融合筛选器，检查当输入目标强度逐渐增加时，两种生成器的序列结构和预测分数是否发生相应变化。

两个生成器在本次选取的五个目标点上，**平均筛选分数均逐点上升**；三个重复实验分别查看时也是如此。连续自回归的分数变化幅度大于连续 VAE。弱、中、强三组生成序列的逐位置 3-mer 分布，均与对应强度训练组最接近；但 VAE 的部分组间差异较小，属于描述性观察。

同时，分数变化范围远小于目标范围，而筛选器在真实开发验证集上也存在明显的预测范围收缩。因此，这些结果**不能证明生成序列的真实表达强度达到目标，也不能只据此判断变化幅度偏小是生成器还是预测器造成的**。本轮没有改变生成器或预测器参数选择，没有计算测试集指标。

## 2. 实验设置

- 数据使用此前固定划分：训练集 8,318 条、开发验证集 1,783 条。数据加载器会读入完整原始数组以检查格式，测试样本没有参与本轮特征提取、拟合或指标计算。测试集在早期探索中曾被查看，不能称为完全未接触的最终测试集。
- 沿用上一轮两个生成器的结构与参数。连续自回归为三阶、三个条件分箱；连续 VAE 使用隐藏层维度 128、潜变量维度 16、KL 权重 0.2，最多训练 120 轮。三个 VAE 实例均训练至第 120 轮。
- 筛选器固定为 motif CNN、全局 1–3-mer 岭回归、位置岭回归，融合权重分别为 0.5、0.4、0.1；不重新选择权重。CNN 用训练数据拟合、开发验证数据早停；岭回归用训练数据拟合。该融合权重此前也在同一个验证集上选择，因此验证集是**重复使用的开发集**。本轮重新拟合后，验证 Pearson 与此前保存值一致。
- 弱、中、强目标取训练集三等分后各组真实 `log10(强度)` 的均值；新增相邻目标的两个中点，共五个目标：约 1.7150、1.9280、2.1410、2.5653、2.9896。这里的标签仍需遵循数据来源报告中对强度单位和测量方式的限制。
- 三次 VAE 训练种子分别为 20260912、20260913、20260914；对应采样种子为 20261030、20261130、20261230。每个目标、每个模型每次采样 500 条，总计 15,000 条。三个原有目标使用上一轮的采样设置，中间目标使用另设的种子；自回归的训练确定性不变，其重复差异来自采样，VAE 差异来自训练和采样。
- 重新生成后，三个原有目标的 GC、位置碱基 L1、逐位置 3-mer 和 5-mer JS 与上一轮保存结果逐项核对一致。此次额外记录生成序列的 SHA-256；上一轮没有保存序列哈希，因此这里的指标核对不应表述为对上一轮逐条序列的哈希验证。
- 两个生成器与筛选器共享训练数据，筛选器不是独立实验测量；对生成序列的分析是模型内的探索性诊断。运行结果保存数据与划分的 SHA-256、每次结果和分数组成。

## 3. 先看预测器在真实验证数据上的误差

按训练集三等分边界，将开发验证集按**真实标签**回顾分组：

| 验证组 | 样本数 | 真实 log 强度均值 | 融合筛选分数均值 | MAE |
| --- | ---: | ---: | ---: | ---: |
| 弱 | 575 | 1.7201 | 2.1930 | 0.4729 |
| 中 | 611 | 2.1367 | 2.2308 | 0.1724 |
| 强 | 597 | 2.9408 | 2.2890 | 0.6569 |

整体验证 MAE 为 0.4316，Pearson 为 0.2866。真实弱组被高估、真实强组被低估的现象在均值上很明显：三个分数组均值靠近中间范围。对没有真实标签的生成样本，我们不能像上表一样计算它的真实 MAE。

上述结果用于提醒预测器的误差边界，**不是**对生成数据的独立校准。开发验证集已用于 CNN 早停和融合权重选择，指标不能视为未经使用的新数据上的最终泛化结果。

## 4. 五个目标下的筛选分数和 GC

表中分数和 GC 为三次实验的均值；分数后的“±”是三次**组均值**的总体标准差，不是单条序列的标准差，也不是置信区间。

| 输入目标 log 强度 | 连续自回归：筛选分数 | 连续 VAE：筛选分数 | 自回归 GC | VAE GC |
| ---: | ---: | ---: | ---: | ---: |
| 1.7150 | 2.1958 ± 0.0047 | 2.2392 ± 0.0079 | 0.4535 | 0.4570 |
| 1.9280 | 2.2123 ± 0.0073 | 2.2478 ± 0.0098 | 0.4475 | 0.4493 |
| 2.1410 | 2.2331 ± 0.0030 | 2.2598 ± 0.0074 | 0.4407 | 0.4474 |
| 2.5653 | 2.2672 ± 0.0052 | 2.2749 ± 0.0057 | 0.4386 | 0.4399 |
| 2.9896 | 2.3016 ± 0.0023 | 2.2901 ± 0.0062 | 0.4298 | 0.4341 |

这五个点中，两个生成器的筛选分数均随着目标增大而逐点上升；三次重复实验各自的五点结果也都上升。对最弱与最强目标，自回归的平均分数差约为 0.1058，VAE 约为 0.0509，而输入目标差约为 1.2746。由于预测器有范围收缩、生成样本又缺乏实测标签，这不是生成误差或真实强度响应幅度。

从均值看，两种生成器的 GC 随目标升高而下降，与此前观察方向一致；但在个别单次实验的相邻目标间出现小幅波动。只看五个离散采样点，也不能证明任意条件下严格单调或平滑。

筛选器三个组成模型各自的组均分都保存在 JSON 中。例如在弱到强的三个原有目标上，自回归的 motif CNN 均分从 2.1586 升至 2.2588、全局岭回归从 2.2471 升至 2.3296、位置岭回归从 2.1760 升至 2.4035；VAE 对应也呈上升。组件并非独立验证器，不能把一致趋势视为三个独立证据。

## 5. 条件变化与局部结构

对弱、中、强三组生成序列，分别与训练集中三个强度组比较逐位置 3-mer JS 散度。以下是三个重复实验均值；每行较小值表示更接近该列训练组，不能跨模型直接解释成真实强度。

| 生成器及输入目标 | 对弱组 | 对中组 | 对强组 |
| --- | ---: | ---: | ---: |
| 自回归：弱 | 0.01662 | 0.0230 | 0.0264 |
| 自回归：中 | 0.0234 | 0.01729 | 0.0242 |
| 自回归：强 | 0.0263 | 0.0241 | 0.01723 |
| VAE：弱 | 0.03238 | 0.0327 | 0.0344 |
| VAE：中 | 0.0322 | 0.03173 | 0.0328 |
| VAE：强 | 0.0342 | 0.0326 | 0.03128 |

在这组对照中，每行均以对应输入强度的训练组为最接近组；自回归的组间区分更明显，VAE 的部分差异较小。由于结果依赖有限样本、训练参考和现有建模方式，不能把微小差异解释为统计显著性。逐位置指标与之前合并所有位置后计算的全局 3-mer JS 不是同一个量。

## 6. 如何使用与下一步

当前结果支持“输入目标改变时，生成序列的组成与筛选器分数也发生变化”，并显示此前的结构分析和现有筛选器给出的变化方向大体一致。它还不能证明真实强度被连续、准确地控制，也不能证明候选序列有功能。

下一步应优先获取或确定与训练数据独立、测量方式匹配的外部验证资源，核查序列和数据来源重叠；若能开展实验，可用同一测量体系对覆盖多个目标的候选进行测量。同时应继续分析预测器在强弱端的误差，避免仅靠模型筛选分数给候选做真实性能排名。

```bash

python scripts/evaluate_m4_condition_response.py \
  --data-dir /path/to/promoter/strenth/data \

python -m unittest discover -s tests -v
```
