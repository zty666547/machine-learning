# M4 CNN 预测误差与训练序列距离检查

## 检查问题与方法

前几轮发现跨簇最近邻距离较大。本轮检查位置感知 motif CNN 的预测误差是否随与训练序列的距离变化。距离采用 50 bp 对齐汉明距离；每条训练折外查询的参照集合是对应外层训练折的全部序列，包括实际拟合部分和用于早停的部分。因此“距离”指到外层可用训练数据的最近距离，早停数据参与了模型选择，但没有参与梯度拟合。

固定原有相似性簇三折及三个模型种子，重新运行已选 CNN；每个种子的整体折外 MAE 均与既有记录一致（容差 1e-8），数据和 NumPy 版本摘要一致。距离分组于本轮结果前固定，配置见[实验规则](../configs/m4_distance_error_2026-11-09.toml)。下表的 MAE 为三个种子均值，样本与距离分组相同。

| 到外层训练数据的最近差异碱基数 | 样本数 | CNN 折外 MAE | 强组样本比例 |
|---|---:|---:|---:|
| 0–21 | 519 | 0.51649 | 39.31% |
| 22–23 | 2,750 | 0.45829 | 34.40% |
| 24 | 2,670 | 0.45910 | 32.40% |
| 25–50 | 2,379 | 0.45240 | 31.86% |

距离与绝对误差的 Pearson 相关系数三个种子均值为 **-0.0383**，变化范围为 -0.0422 至 -0.0363。本轮没有看到简单的“越远，误差越大”的趋势；较近距离组误差反而更大。

这一现象需要谨慎解释：0–21 组的强组比例较高（39.31%），而模型对强组的误差本就较大；分组间标签分布不同可能影响总体 MAE。同组内，0–21 距离组有 204 条强组样本，其强组 MAE 约 0.85086；其他距离组强组 MAE 约 0.72690–0.75439。组内差异也不能直接证明距离导致误差变化，还可能受其他数据特征影响，样本并非独立随机试验。

## 边界与复现

弱、中、强组依据训练标签三分位数确定。对齐汉明距离将每个位置同等看待，不能代表全部生物学相似性；相关不代表因果。三次种子共享同一分折，不是三个独立测试；没有本轮模型选型或调参。开发验证集和测试集仅由加载器作格式检查，本轮没有提取其特征或计算其指标。无外部数据评价或湿实验，不能用于证明生成序列的真实活性。

```sh
for seed in 20260912 20260913 20260914; do
  OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 VECLIB_MAXIMUM_THREADS=1 \
    python scripts/audit_distance_error.py --data-dir "$DATA_DIR" --seed "$seed" \
    --output "reports/m4_distance_error_seed_${seed}.json"
done
```

逐种子结果记录数据摘要、分组数、组内强度分布与误差；不输出训练序列。
