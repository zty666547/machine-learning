# M4：相似性簇折外目标筛选检查

## 为什么做这项检查

上一轮在已反复参与模型开发的验证集上检查目标筛选，结果可能受到模型选择和早停的影响。本轮改用训练集内按相似性簇划分的三折，检查评分器能否从未参与本折训练的已标注序列中，选出实际强度接近目标的序列。

每折分别用其余两折的训练标签划分弱、中、强三组，并计算各组 log10 强度均值作为本折目标；候选池是整折留出序列。两个评分器分别选出预测值距离目标最近的 50 条，之后才用其已有标签计算平均真实距离。M3 融合器使用原有 CNN 与两个岭回归分支，CNN 在外层训练部分内再划出早停子集；岭回归和 SVR 使用整个外层训练部分。规则、折划分和参数见[预先固定的配置](../configs/m4_target_oof_audit_2026-11-15.toml)。

随机参照是留出池中所有记录的平均真实距离，即从中均匀随机抽取 50 条时平均距离的期望；事后最优参照直接按真实标签选 50 条，仅表示知道答案后的下界，不能用于未知标签的候选。

## 结果

下表数值是三折各自结果的平均，每折目标由该折的外层训练部分确定，因此并非完全相同。单位均为 **log10 强度距离**，数值越小，表示选中序列已有标签越接近对应目标。

| 目标 | 随机参照 | M3 筛选 | SVR 筛选 | 事后最优参照 |
|---|---:|---:|---:|---:|
| 弱 | 0.6112 | 0.3415 | 0.3650 | 0.0076 |
| 中 | 0.4620 | 0.3576 | 0.3884 | 0.0062 |
| 强 | 0.8530 | 0.7638 | 0.7739 | 0.0212 |

三折平均来看，两个评分器在三个目标上的结果均优于随机期望，但距离事后最优仍较远。折间存在差异，例如强目标 SVR 三折分别为 0.6628、0.7503、0.9087；第三折随机参照约为 0.8589，因此不能把三折平均结果理解成每一折都优于随机参考。

对于中目标，M3 和 SVR 筛出的序列，其预测值到目标的平均距离分别约为 0.0019 和 0.0023；对应已有标签到目标的平均距离却为 0.3576 和 0.3884。这是同一批筛中序列的两种距离比较：**预测分数接近目标，并不保证真实强度同样接近**。表中指标是所选序列到目标的真实距离，不是通常意义上的模型预测 MAE。

## 边界和复核

每折被评估序列所属的相似性簇没有进入该折模型训练，目标也只从该折训练部分的标签计算。但模型结构、M3 融合权重及这些数据此前已用于多轮开发；三个折也不是三个独立数据集。因此这是训练数据内的探索性折外诊断，不是独立外部验证，也不是生成序列的实测结果。本轮没有使用验证集或测试集进行新的评估；早期开发已使用过验证集及部分测试结果。折外 CNN 的早停方式也与已部署 M3 版本不同，不能将两者视为完全相同的训练流程。

重新拟合的两个评分器的整体折外 MAE 与既有记录一致；运行环境及输入摘要记录在[结果 JSON](m4_target_oof_audit_2026-11-15.json) 中。900 条选择记录的标签、目标、分折和参照值经独立代码核对，同环境重复运行的 JSON 与 CSV 完全一致；项目现有 55 项测试通过。训练集中的 900 条选择记录保存为本地 `outputs/m4_target_oof/training_oof_research_selections.csv`，只是对已标注样本的研究检查，不是新生成序列或最终实验名单，按仓库规则不上传。

## 复现

需先按既有 M4 CNN 多种子流程生成 `outputs/m4_cnn_ensemble/member_20260912.npz`。在 Python 环境安装 NumPy 2.5.4、scikit-learn 1.9.1，并提供原始课程序列和标签目录：

```sh
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 VECLIB_MAXIMUM_THREADS=1 \
python scripts/audit_target_oof.py --data-dir "$DATA_DIR" \
  --cnn-member outputs/m4_cnn_ensemble/member_20260912.npz \
  --output reports/m4_target_oof_audit_2026-11-15.json \
  --selected-csv outputs/m4_target_oof/training_oof_research_selections.csv
```

脚本会核对数据、划分、CNN 成员与历史协议摘要，以及既有折外 MAE；CNN 成员原使用 NumPy 2.3.5，详见结果 JSON。
