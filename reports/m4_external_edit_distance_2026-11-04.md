# M4：外部候选序列的插入、删除相似性补充排查

日期：2026-11-04。本轮对上一轮已探索评价的 1,552 条外部记录，补充带插入和删除的序列重叠筛查，并观察筛查对既有指标的影响。规则在运行前固定于 [协议配置](../configs/m4_edit_distance_protocol_2026-11-04.toml)。

## 1. 总体结果

在本轮规定的 50 bp 窗口、±5 bp 位置偏移和最多 5 次编辑的范围内，**没有发现新增的课程数据近似匹配**。因此，本轮没有排除记录，剩余 1,552 条；上一轮融合筛选器的记录层面指标保持 Spearman 0.1360、AUROC 0.7887、平均精度 AP 0.2495。

该检查进一步缩小了一种明确的重叠风险，但**不能证明外部数据完全独立**。结果仍是对已经查看过的外部已有序列所做的开发期探索，不能证明新生成序列的真实启动子活性或强度。

## 2. 比较方法

沿用上一轮 1,552 条外部实验记录、课程全部 11,884 条序列和既有固定预测分数；不重新训练或选择模型。逐条核验外部评分文件、原始报告实验文件、参考基因组、课程数据和固定划分的校验值。

对每条外部记录：

1. 从已经核验过的 150 bp 报告实验片段中，按原来的截取位置前后移动最多 5 bp，得到 11 个 50 bp 窗口。
2. 对每个窗口同时比较原方向和反向互补方向，共 22 个查询窗口；与课程训练、验证和测试集中的全部 50 bp 序列比较。课程测试序列仅用于重叠筛查；它在项目更早期曾被查看，不能称为从未接触的最终测试集。
3. 用**全局编辑距离（Levenshtein 距离）**衡量完整两个窗口之间的最少操作数，替换、插入、删除各计 1 次。只要任一窗口与任一课程记录距离不大于 5，即标记为本轮匹配。

“最多 5 次编辑”是本项目与此前阈值衔接所用的排查规则，不是生物学上判断序列独立的通用标准。它与之前“最多 5 个位置不同”的逐位比较不同：后者不允许插入或删除。此外，本轮两个比较窗口长度均固定为 50 bp；没有覆盖超过 5 次编辑、偏移超过 ±5 bp、其他长度或更广义的同源关系。

计算采用分块索引和精确的全局编辑距离核验；加速实现使用 [Edlib](https://github.com/Martinsos/edlib) 的全局对齐，脚本在缺少 Edlib 时会使用精确的 Python 动态规划，速度可能较慢。分块使用 6 个互不重叠的参考序列片段，并搜索不超过 5 bp 的片段位移：若全局编辑距离不大于 5，至少有一个片段未被编辑并被检出，之后才由全局距离计算确认。该索引用于加速，不把片段命中本身当成序列匹配。

| 项目 | 数量 |

| 输入外部实验记录 | 1,552 |
| 本规则内新增匹配 | 0 |
| 本规则内未发现匹配 | 1,552 |

由于没有记录被本轮规则排除，复用上一轮固定分数计算的记录层面 Spearman、AUROC、AP 与之前完全相同。唯一输入中位数复核也没有变化。这是对已有结果的**事后敏感性检查**，不是重新选模或一轮新独立测试。

| 统计单位 | 记录或序列数 | Spearman | AUROC | AP |
| --- | ---: | ---: | ---: | ---: |
| 实验记录 | 1,552 | 0.1360 | 0.7887 | 0.2495 |
| 唯一 50 bp 输入，中位数汇总 | 1,541 | 0.1349 | 0.7873 | 0.2495 |

外部 active 记录仍为 97 条、inactive 为 1,455 条。外部实验测量完整 150 bp 片段，模型只接收 50 bp，其连续数值和课程标签也不是同一测量尺度；不能把 AUROC 当成准确率或将预测分数当成实测强度。

## 4. 核验和局限

- 单元测试比较分块索引与不依赖该索引的逐条编辑距离，覆盖替换、插入、删除、阈值边界和随机变体；另以 2,000 组变化长度、操作及阈值的样例核对 Edlib 与 Python 动态规划，结果一致。
- 随机抽取 6 条实际外部记录，对其每条的全部 22 个查询窗口与 11,884 条课程序列逐一使用 Edlib 全局编辑距离穷举比较，结果与索引筛查一致。该抽查不等同于对所有实际记录做穷举。
- 在相同环境中重复执行后，汇总 JSON 和逐条 CSV 一致；原有指标从冻结的上一轮逐条分数重新计算，并与之前记录核对。
- 这批外部数据及其标签和结果已经在开发阶段查看，不能包装成从未使用过的最终独立测试集。下一步若希望支撑真实强度或功能结论，仍需寻找新的独立测量资源，或对模型生成候选开展适用的实验。

## 5. 复现

先按 [上一轮外部评价记录](m4_external_screening_evaluation_2026-11-03.md)生成固定的逐条分数文件，并准备原始报告数据与参考基因组。安装 Edlib 为可选加速步骤，版本固定为本轮使用的 1.3.9.post1；不安装时使用较慢的纯 Python 后备算法。

```bash
python -m pip install 'edlib==1.3.9.post1'  # 可选加速
python scripts/audit_external_edit_distance.py \
  --data-dir /path/to/promoter/strenth/data \
  --mpra outputs/m4_external/source/tss_expression.txt \
  --genome outputs/m4_external/source/U00096.2.fasta \
  --scores outputs/m4_external/screening_scores_2026-11-03.csv
python -m unittest discover -s tests -v
```

汇总见 [JSON](m4_external_edit_distance_2026-11-04.json)，逐条筛查明细为 `outputs/m4_external/edit_distance_audit_2026-11-04.csv`。编辑距离字段为空表示该规则内未检出匹配，**不是**距离为零。本地输出不随 Git 提交；不同后端运行时记录的 Edlib 版本字段可能不同，但匹配结果应一致。
