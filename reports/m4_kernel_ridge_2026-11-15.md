# M4：核岭回归与 SVR 的预测及目标筛选对照

## 目的和方法

上一轮的 SVR 线性校准没有带来一致改善。本轮尝试另一个非线性预测器——径向基核岭回归（RBF kernel ridge regression，KRR）。它先根据样本特征计算相似度，再用带正则化的平方误差目标拟合强度；已有 SVR 则使用不同的损失函数和训练方式。两者都使用 RBF 核，因此本轮不是对完全不同序列表示的比较。

模型配置在产生本轮结果前固定：KRR 正则系数 `alpha=1.0`，每折仅用外层训练特征拟合标准化，RBF 带宽采用与原 SVR `gamma=scale` 相同的计算规则。两者使用相同位置 1-mer/2-mer、全局 1–3-mer 和 GC 特征、相同外层训练样本与留出样本；SVR 折外预测来自[上一轮固定记录](m4_svr_nested_calibration_2026-11-15.md)，数据和预测文件摘要均经核验。详见[预先固定配置](../configs/m4_kernel_ridge_2026-11-15.toml)。

## 强度预测

| 训练集折外指标 | 原 SVR | 核岭回归 |
|---|---:|---:|
| 总体 MAE | 0.45760 | 0.46563 |
| Pearson | 0.24349 | 0.23081 |
| Spearman | 0.22766 | 0.20822 |
| 弱标签组 MAE | 0.47406 | 0.51049 |
| 中标签组 MAE | 0.18948 | 0.20569 |
| 强标签组 MAE | 0.71008 | 0.68145 |
| 预测值标准差 | 0.19231 | 0.19936 |

总体指标按全部 8,318 条训练集折外预测计算；各标签组 MAE 是三折组内 MAE 的简单平均。每折组别由该折外层训练标签的三分位点确定，并在评价时根据留出标签回顾分组。标签标准差为 0.63657，两种模型的预测分布都比标签分布窄。

该固定配置下，KRR 的强标签组 MAE 较低，但总体、弱组、中组 MAE 及两项相关系数均不如 SVR。这个现象只能作为特定模型和参数下的对照，不能归因于损失函数或断言所有 KRR 都不如 SVR。

## 目标筛选

每折使用其训练部分的弱、中、强标签均值作为三个目标；分别让两个预测器从同一留出池中选择预测值最接近目标的 50 条，再用已有标签计算到目标的平均距离。下表是三折简单平均，单位为 log10 强度距离；它不是预测 MAE。

| 输入目标 | SVR 所选记录的真实距离 | KRR 所选记录的真实距离 |
|---|---:|---:|
| 弱 | 0.3650 | 0.4712 |
| 中 | 0.3884 | 0.3820 |
| 强 | 0.7739 | 0.7906 |

尽管 KRR 在已有强标签组上的预测 MAE 较低，它挑出的强目标序列到目标的平均真实距离反而略高。前者是在已知哪些序列属于强标签组之后评价预测，后者是在不知道留出标签的情况下选择序列；两者回答的问题不同。中目标距离略有下降，但该变化来自同一训练数据的探索性评价，不应认定为对新数据的稳定改善。

## 边界和复核

这是一个固定分折、每种方法各一组参数的训练集内部实验；模型和数据此前已参与项目开发，不能视为独立测试或生物实验验证。未使用验证集或测试集进行本轮拟合及评价；课程测试集在更早开发中曾被查看。未导出 KRR 部署模型，未替换当前筛选器。内存、耗时及参数敏感性未进行系统对比。

8,318 条记录的样本与标签、目标筛选、指标及簇分离经独立核对；第一折使用独立核矩阵和线性方程求解重算，最大预测差为 0；同环境重复运行的 JSON 和 CSV 一致，项目 55 项现有测试通过。完整数值和输入摘要见[JSON](m4_kernel_ridge_2026-11-15.json)；本地 `outputs/m4_kernel_ridge/oof_predictions.csv` 是已有训练样本研究记录，按仓库规则不上传。

## 复现

安装 NumPy 2.5.4、scikit-learn 1.9.1 等依赖，先按[上一轮说明](m4_svr_nested_calibration_2026-11-15.md)生成 SVR 折外记录；`DATA_DIR` 指向课程原始大肠杆菌数组目录：

```sh
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 VECLIB_MAXIMUM_THREADS=1 \
python scripts/evaluate_kernel_ridge.py --data-dir "$DATA_DIR" \
  --svr-oof outputs/m4_svr_nested_calibration/oof_predictions.csv \
  --output reports/m4_kernel_ridge_2026-11-15.json \
  --predictions outputs/m4_kernel_ridge/oof_predictions.csv
```
