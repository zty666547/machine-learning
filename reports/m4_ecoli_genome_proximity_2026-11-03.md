# M4：外部候选序列的基因组邻近性排查

日期：2026-11-03。本轮承接 [偏移近似匹配与重复记录复核](m4_ecoli_mpra_refined_audit_2026-11-03.md)，检查剩余 6,258 条外部候选窗口是否位于课程数据序列附近。本轮没有训练、选择或评价模型。

## 1. 总体结果

课程数据 11,884 条 50 bp 序列都能在本轮使用的 **U00096.2** 参考基因组上找到至少一个完全匹配位置；这里的“定位”只说明片段匹配到参考序列，不代表已经逐条确认其原始 TSS 或生物学功能。

上一轮剩余的 6,258 条外部记录中，**4,706 条**的 50 bp 窗口与至少一个已定位的课程序列窗口相距不超过 200 bp；另有 **1,552 条**不在此范围内。这是预先设定的保守排查规则，1,552 条仍只是候选，不能称为已经证实独立的测试集。

这 1,552 条中原研究标记为 active 的有 **97 条**、inactive 的有 **1,455 条**。类别明显不平衡，后续评价时不能只报告总体准确率。

## 2. 本轮怎样比较

1. 沿用此前固定的课程数据划分与公开参考基因组 U00096.2。将课程 50 bp 序列在参考基因组上以正向和反向互补两个方向寻找**完全匹配**；考虑环状基因组跨越参考序列首尾的情况。若一个序列在多个位置匹配，全部匹配位置都纳入。
2. 对此前通过位置核验和两轮序列重叠筛查的 6,258 条外部记录，复核对应 50 bp 窗口的基因组位置和方向。
3. 计算外部窗口与所有已匹配课程窗口之间的最小**区间间隔**，正反两条链均纳入邻近性筛查。比如相隔 10 bp 指两个 50 bp 区间之间有 10 个碱基；间隔 0 同时包含两个区间重叠和紧邻的情况。
4. 实验前固定以 **200 bp 区间间隔**作为本轮保守筛查阈值，并另外报告 0、50、100 bp 下的数量，展示结果对阈值的敏感性。

200 bp 是项目内部排查阈值，不是生物学独立性的通用界限。测量距离使用的是外部 **50 bp 窗口**，不是原报告实验的完整 150 bp 片段。

## 3. 定位结果与距离分布

课程训练、验证、测试集分别有 8,318、1,783、1,783 条序列，本轮都能在参考基因组中找到至少一个完全匹配位置。公开数据和课程数据的文件校验值、课程各划分定位结果见 [机器可读结果](m4_ecoli_genome_proximity_2026-11-03.json)。

以下统计的分母均为 **6,258 条外部候选记录**。每个距离范围包含更小的范围，因此行间不能相加：

| 距离任意已定位课程序列窗口的最小间隔 | 外部记录数 |
| --- | ---: |
| 0 bp：重叠或紧邻 | 1,882 |
| 不超过 50 bp | 3,088 |
| 不超过 100 bp | 3,832 |
| 不超过 200 bp | 4,706 |
| 大于 200 bp | 1,552 |

这说明，之前按固定长度序列差异与小范围偏移检查时没有命中，并不代表外部候选来自远离课程样本的基因组区域。例如，部分片段虽然没有满足之前设置的序列匹配规则，但其基因组区间仍然重叠或相邻。

在间隔不超过 200 bp 的外部记录中，分别有 3,427 条邻近至少一个训练序列位置、1,233 条邻近至少一个验证序列位置、1,247 条邻近至少一个测试序列位置。同一条外部记录可以同时邻近多个划分，**三个数字不能相加**。测试集序列仅用于位置排查，本轮未计算测试集预测表现；项目早期曾查看测试集，不能称其为从未接触的最终测试集。

## 4. 距离筛查后的候选与限制

在本轮规则下，距离所有已定位课程窗口均大于 200 bp 的候选为：

| 指标 | 数量 |
| --- | ---: |
| 外部实验记录 | 1,552 |
| 不同 50 bp 输入 | 1,541 |
| 原研究标记 active 的记录 | 97 |
| 原研究标记 inactive 的记录 | 1,455 |
| 处理后实验值不大于 0 的记录 | 757 |

这些数字是记录层面的描述，重复 50 bp 输入尚未被自动合并。原研究的 active/inactive 使用其自身实验阈值；其处理值可为负，不能直接取 `log10` 或与课程标签当作同一数值尺度。

本轮已映射的课程序列只是参考基因组上的**精确序列匹配位置**；多个相同匹配位置不一定都是该课程样本真实来源。两项实验还存在测量体系和上下文差异：外部研究测量完整 150 bp 片段，我们的预测器只输入 50 bp。更远的距离也不能排除同源性、长距离调控关系或其他泄漏路径。

因此这份清单可作为下一轮**进一步审查的候选**，不能直接宣称无数据泄漏，也不能用它证明新生成序列的实际启动子活性。

## 5. 校验与后续建议

- 课程输入、参考基因组和划分的哈希值均核对；上一轮筛查重新运行后，汇总及逐条数据与已有文件一致。
- 位置计算的单元测试覆盖正负链、跨参考基因组首尾的匹配，以及随机条件下与穷举距离计算的一致性。
- 如需做外部探索，先明确重复记录的评价单位、数值尺度、极不平衡类别下的指标及候选排除标准。对不同 200 bp 规则或模型反复比较后，同一批数据不能再当作未经使用的最终独立测试集。
- 还应考虑更宽范围或带插入/删除的相似性检查，并区分对已有外部序列的预测评价与对模型新生成序列的湿实验验证。

## 6. 复现

先按上一轮记录准备公开参考基因组及 `urtecho_tss_refined_overlap.csv`，再在仓库根目录运行：

```bash
python scripts/audit_ecoli_genome_proximity.py \
  --data-dir /path/to/promoter/strenth/data \
  --genome outputs/m4_external/source/U00096.2.fasta \
  --refined-rows outputs/m4_external/urtecho_tss_refined_overlap.csv
python -m unittest discover -s tests -v
```

逐条输出在 `outputs/m4_external/urtecho_genome_proximity.csv`，包含每条外部候选的窗口位置、到各课程划分的最近区间间隔及 200 bp 标记。输出目录为本地派生文件，不随 Git 提交。
