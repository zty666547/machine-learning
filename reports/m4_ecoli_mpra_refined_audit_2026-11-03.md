# M4：外部报告基因数据的偏移近似重叠与重复记录复核

日期：2026-11-03。本轮在 [上一轮外部数据审计](m4_ecoli_mpra_audit_2026-11-03.md)的基础上，检查窗口偏移之后仍有少量碱基差异的近似匹配，并核查剩余记录的重复 50 bp 输入。本轮没有训练或评价预测器。

## 1. 总体结果

上一轮保留了 6,264 条候选记录。本轮补充检查后，其中 **6 条**在窗口移动后与课程数据的某条 50 bp 序列相差不超过 5 个碱基；依照本轮排查规则，它们被标为新增重叠。剩余 **6,258 条记录、6,221 个不同的 50 bp 输入**。

剩余数据只是更严格排查后的候选，不是已证实独立的外部测试集。此次仍未检查带插入或删除的比对、偏移范围外的相似片段、基因组邻近关系及全部潜在同源性。

## 2. 本轮补充了什么检查

延续上一轮已通过坐标核验和重叠筛查的 6,264 条候选。对每条外部数据的 150 bp 原片段：

1. 将原 50 bp 窗口分别向前、向后移动 0–5 bp，共检查 11 个位置；
2. 每个位置分别比较正向和反向互补序列，与课程训练集、验证集和测试集的全部 50 bp 序列比较；
3. 逐位比较时允许最多 5 处不同，即至少 45/50 位相同，不允许插入或删除；只要任何一个位置及方向命中，即标为本轮新增近似重叠。

上一轮已检查固定窗口最多 5 个错配和偏移窗口完全匹配；本轮填补的是**偏移之后仍存在 1–5 个错配**的情况。5 个错配和 ±5 bp 是本项目的排查规则，不是保证生物学独立性的通用阈值。

脚本会核查课程数据、划分及公开来源文件的校验值，核对上一轮逐条记录与来源文件和坐标的一致性，并对每个上一轮候选重新核验其满足原筛查规则。测试集序列仅用于排查重叠，本轮没有计算测试集模型指标。测试集在项目早期曾被查看，不能称为从未接触的最终测试集。

## 3. 新发现的重叠

| 上一轮候选检查结果 | 记录数 |
| --- | ---: |
| 上一轮候选 | 6,264 |
| 新增偏移近似重叠 | 6 |
| 本轮筛查后剩余 | 6,258 |

按每条新增重叠记录在所有方向和偏移中的最少错配数统计：1 处、2 处、4 处错配各 1 条，5 处错配 3 条。新增的 6 条中，5 条涉及课程训练集，1 条涉及验证集；没有命中测试集。按划分统计允许同一条外部记录命中多个划分，原则上不可直接相加。

## 4. 剩余记录的重复情况和标签

剩余 6,258 条中，公开研究的二分类标记为 active 的有 **879 条**、inactive 的有 **5,379 条**；处理后的实验值中有 **2,525 条不大于 0**。这些标签和数值使用该研究自己的实验体系，不能直接等同于课程中的强、中、弱分组，也不能对非正数直接取对数。

从模型输入角度看：

- 6,258 条记录对应 6,221 个不同的 50 bp 窗口。
- 有 **21 组**窗口重复，共涉及 58 条记录，比按窗口去重后的数量多出 37 条。
- 21 组重复窗口中，没有组内 active/inactive 标记冲突；有 **5 组**对应的处理后活性值不同，有 **6 组**对应的完整 150 bp 片段不同。

这说明相同的 50 bp 输入可能对应不同的完整实验片段或实验数值。当前未对这些记录取平均、删除或重新贴标签；后续选择以“记录”还是“唯一序列”为评价单位时，需要先固定规则并报告影响。

## 5. 检查及使用边界

- 新增筛查基于分块索引寻找最多 5 处替换的匹配；单元测试覆盖偏移、错配、反向互补和重复记录计数。
- 将本次全部 6 条新增匹配及另选的 6 条未匹配记录，用不依赖该索引的逐位穷举比较复核，最少错配结果一致。
- 从同一输入重新运行本轮流程，汇总 JSON 和逐条 CSV 结果逐字节一致。
- 外部实验测量 150 bp 完整片段，本项目预测器只接收其中一个 50 bp 窗口；即使经过序列排查，两者也不是完全相同的预测任务。
- 后续如需做跨实验探索，可先固定候选规则、评价单位和指标，再比较预测分数与外部实验值的排序关系；不能用该数据反复选模型后再将同一结果作为独立最终测试，更不能把对已有外部序列的评价称为生成序列的实验验证。

## 6. 复现

先按上一轮报告下载固定版本的原始数据与参考基因组，然后在仓库根目录重新生成上一轮审计及本轮结果：

```bash
DATA_DIR="/path/to/promoter/strenth/data"
python scripts/audit_ecoli_mpra_external.py \
  --data-dir "$DATA_DIR" \
  --mpra outputs/m4_external/source/tss_expression.txt \
  --genome outputs/m4_external/source/U00096.2.fasta
python scripts/refine_ecoli_mpra_overlap.py \
  --data-dir "$DATA_DIR" \
  --mpra outputs/m4_external/source/tss_expression.txt \
  --genome outputs/m4_external/source/U00096.2.fasta \
  --prior-rows outputs/m4_external/urtecho_tss_overlap.csv
python -m unittest discover -s tests -v
```

机器可读汇总为 [本轮 JSON](m4_ecoli_mpra_refined_audit_2026-11-03.json)。`outputs/m4_external/urtecho_tss_refined_overlap.csv` 对上一轮全部 6,264 条候选逐条记录本轮命中情况、最少错配、偏移、方向和课程划分；对本轮剩余项还记录相同 50 bp 输入的记录数和不同 150 bp 上下文数。错配字段为空表示未在本规则内找到匹配，**不是**错配数为零。输出目录为本地派生文件，不随 Git 提交。
