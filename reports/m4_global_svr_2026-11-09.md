# M4 相同全局特征下 SVR 与岭回归比较

## 目的与方法

上一轮用 RBF SVR 替换融合中的全局岭回归时，SVR 同时使用了更丰富的位置特征，模型与特征两个因素混在一起。本轮令两者都只使用**全局 1–3-mer 和 GC**，在相同相似性簇三折、相同外层训练样本上比较。岭回归沿用融合器固定 alpha=10；SVR 沿用 C=1、epsilon=0.1、gamma=`scale`。这是一组固定设置，并不表示两种方法都经过最佳调参。实验配置在结果前固定，见[配置](../configs/m4_global_svr_2026-11-09.toml)。

随后固定 0.5 CNN + 0.4 全局模型 + 0.1 位置岭回归，比较替换前后融合结果；共享相同训练内早停 CNN 和位置岭回归预测。CNN 成员与之前数据、分折和指标核对，原分量融合的折外与开发验证 MAE 复现上一轮结果。每折标准化与 gamma 均只使用该折训练数据。

## 结果

单独分量在训练集内部三折的折外表现：

| 指标 | 全局岭回归 | 相同全局特征的 SVR |
|---|---:|---:|
| MAE | 0.47000 | 0.47425 |
| Pearson | 0.19662 | 0.15794 |
| Spearman | 0.18616 | 0.14081 |
| 弱组 MAE | 0.53640 | 0.45627 |
| 中组 MAE | 0.19482 | 0.20169 |
| 强组 MAE | 0.67867 | 0.76469 |

在这个固定配置下，全局 SVR 弱组误差下降，但整体 MAE 和相关性变差，强组误差升高。只看全局特征，不能认为此次 SVR 比原全局岭回归全面更好。

放入固定融合后：

| 折外指标 | 原分量融合 | 全局 SVR 替换方案 |
|---|---:|---:|
| MAE | 0.45725 | 0.45513 |
| Pearson | 0.24992 | 0.24557 |
| Spearman | 0.22719 | 0.21462 |
| 弱组 MAE | 0.49511 | 0.46111 |
| 中组 MAE | 0.16799 | 0.16219 |
| 强组 MAE | 0.70854 | 0.74197 |

融合后整体 MAE 略降，弱组改善，强组与折外排序相关性变差。上一轮使用位置和全局特征的 SVR 替换方案折外 MAE 为 0.45387、Spearman 为 0.23700；它与本轮共用相同数据、分折和 CNN，但这两组都是开发探索，数值差异不能直接解释为位置特征的因果效应，也不足以确立统计显著性。

开发验证集上的融合 MAE 为 0.43060 与 0.42760，强组 MAE 为 0.69105 与 0.71983；开发验证集已反复使用，并非独立评价。本轮不按开发验证选择权重或替换模型，现有 M3 融合筛选器保持不变。

## 边界与复现

训练集 8,318 条、开发验证 1,783 条；强弱组基于训练标签三分位数。CNN 采用训练内部早停，不是原 M3 使用开发验证早停的部署流程。SVR 确定性训练，本轮只检查固定的一套分折；测试数据仅由加载器检查格式，没有提取特征或计算测试指标，无新外部数据或湿实验。未保存新 SVR 推理检查点。

在原 CNN 成员预测文件存在、NumPy 2.5.4 和 scikit-learn 1.9.1 环境下：

```sh
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 VECLIB_MAXIMUM_THREADS=1 \
 python scripts/evaluate_global_svr.py --data-dir "$DATA_DIR" \
 --cnn-member outputs/m4_cnn_ensemble/member_20260912.npz \
 --output reports/m4_global_svr_2026-11-09.json
```

同一环境和输入重复运行的结果 JSON 逐字节一致。此前 CNN 成员来自 NumPy 2.3.5 环境，已核对数据、分折及原 MAE。详细分组和摘要见[结果文件](m4_global_svr_2026-11-09.json)。
