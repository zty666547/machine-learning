# M4 RBF 支持向量回归与线性预测器对照

## 方法

本轮尝试径向基核支持向量回归（RBF SVR）：利用标准化后的序列特征计算样本之间的非线性相似关系，并拟合 log10 强度。固定 C=1、epsilon=0.1、gamma=`scale`，与固定 alpha=1000 的岭回归比较；参数和评价规则在本轮结果前固定，见[配置](../configs/m4_rbf_svr_2026-11-09.toml)。

两者使用位置 1-mer/2-mer、全局 1–3-mer 和 GC 相同特征，使用同一个相似性簇三折、每折全部外层训练样本（约 5,545 条）。各折标准化和 SVR 的 gamma 只由该折训练特征确定。线性对照的折外与开发验证 MAE 复现之前 Extra Trees 实验中的相同线性结果（容差 1e-8）。

## 结果

| 训练集折外指标 | 线性岭回归 | RBF SVR |
|---|---:|---:|
| MAE | 0.47642 | 0.45760 |
| Pearson | 0.22886 | 0.24349 |
| Spearman | 0.20399 | 0.22766 |
| 弱组 MAE | 0.51776 | 0.47416 |
| 中组 MAE | 0.24468 | 0.18874 |
| 强组 MAE | 0.66672 | 0.70981 |
| 预测标准差 / 标签标准差 | 0.41419 | 0.30211 |

在该次固定配置和分折下，SVR 的总体 MAE、相关性、弱组和中组 MAE 优于线性对照，但强组 MAE 升高、预测范围进一步收缩。强组平均有符号误差从 -0.64111 变为 -0.70368，表明强组低估加重；不能称为全面改善。

开发验证集 MAE 为 0.45891 与 0.43873、Spearman 为 0.21007 与 0.23823，但开发验证集已被反复使用，不能作为独立验证。这里比较的是两个各自固定的一组参数，不能推广为 SVR 普遍优于所有线性方法。SVR 是确定性模型，本轮没有把重复计算当作不同随机种子实验。最终拟合的 8,318 条训练样本中 7,063 条成为支持向量，会影响预测计算和模型存储成本；未记录可跨机器比较的运行时间。

## 数据边界与复现

训练集 8,318 条、开发验证集 1,783 条；强弱组边界由训练标签三分位数确定。仅使用一个固定外层分折方案；测试数组只由加载器检查格式，未提取测试特征或计算指标。外部数据和湿实验均未用于本轮。本次方法尚未保存推理检查点，也没有替换现有融合筛选器；与使用不同训练数量及早停方式的 CNN/M3 数值不可直接视作严格配对比较。

使用 Python 3.12、NumPy 2.5.4 和 scikit-learn 1.9.1；按需安装项目 trees 可选依赖，固定相应版本后运行：

```sh
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 VECLIB_MAXIMUM_THREADS=1 \
 python scripts/evaluate_rbf_svr.py --data-dir "$DATA_DIR" \
 --output reports/m4_rbf_svr_2026-11-09.json
```

[结果文件](m4_rbf_svr_2026-11-09.json)包含分折数、支持向量数、数据摘要及组内指标；跨数值环境可能有差异。
