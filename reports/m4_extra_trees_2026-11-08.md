# M4 强度预测器：随机树与线性模型对照

## 目的与方法

针对预测范围偏窄以及两端误差的问题，探索不同于循环神经网络的建模方式。Extra Trees 是多棵随机回归树的集成：每棵树按特征条件逐步划分样本，再将多棵树的预测取平均。它可以表达序列特征之间的非线性关系。

按事先固定的配置使用 128 棵树、最小叶节点 8 条、每次考虑一半特征；位置 1-mer、位置 2-mer、全局 1–3-mer 和 GC 特征与线性岭回归相同。两种模型每折均使用完整外层训练样本，岭回归正则系数为 1000。配置见[实验配置](../configs/m4_extra_trees_2026-11-08.toml)。

## 结果

训练集相似性簇三折折外指标为三种子均值：

| 指标 | 线性岭回归 | Extra Trees |
|---|---:|---:|
| MAE | 0.47642 | 0.46551 |
| Pearson | 0.22886 | 0.22836 |
| Spearman | 0.20399 | 0.21532 |
| 弱组 MAE | 0.51776 | 0.53838 |
| 中组 MAE | 0.24468 | 0.17487 |
| 强组 MAE | 0.66672 | 0.68318 |
| 预测标准差 / 标签标准差 | 0.41419 | 0.18137 |

树模型的总体 MAE 和 Spearman 有所改善，但主要伴随中组误差下降；弱组和强组误差都上升，预测值范围更窄。开发验证集 MAE 分别为 0.45891 和 0.44244，Pearson 分别为 0.22030 和 0.25449；该验证集已多次用于开发，不是独立验证。不能根据总体 MAE 就认定树模型全面更好，也不足以替换融合筛选器。

## 数据边界与复现

固定训练集 8,318 条、开发验证集 1,783 条。每折拟合约 5,545 条；分组边界由训练标签三分位数确定。三个种子共用同一组外层折，不能当作独立测试集；线性模型确定性强，三次相同。测试数组只由加载器检查格式，未用于提取特征或评价；无外部数据和湿实验。本次模型未导出推理检查点，结果仅作探索。RNN 使用不同的拟合/早停样本数，不能直接作等训练量比较。

实验环境 Python 3.12、NumPy 2.5.4、scikit-learn 1.9.1；安装可选依赖并固定 NumPy 后，将 `DATA_DIR` 设为课程数据路径：

```sh
python -m pip install 'numpy==2.5.4' 'scikit-learn==1.9.1'
for seed in 20260912 20260913 20260914; do
  OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 VECLIB_MAXIMUM_THREADS=1 \
    python scripts/evaluate_extra_trees.py --data-dir "$DATA_DIR" --seed "$seed" \
    --output "reports/m4_extra_trees_seed_${seed}.json"
done
```

模型随机性和数值库版本可能造成跨环境差异。每种子的详细结果包含数据散列、版本、总体和分组指标。
