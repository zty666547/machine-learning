# M4 强度预测器：排序目标与非线性特征探索

## 目标与结果

围绕现有预测器强弱两端误差较大、排序能力有限的问题，本轮尝试两条不同路线：在普通 RNN 的训练目标中增加成对排序项；在位置 k-mer 岭回归中加入随机傅里叶特征以表达非线性关系。参数、数据划分和比较规则在查看结果之前固定，见[实验配置](../configs/m4_ranking_rff_2026-11-06.toml)。

以下为训练集内部按相似性簇划分的三折折外（OOF）预测指标，三次随机种子的均值 ± 总体标准差；MAE 越小越好，Pearson 和 Spearman 越大越好。

| 配对比较 | 模型 | MAE | Pearson | Spearman | 弱组 MAE | 强组 MAE |
|---|---|---:|---:|---:|---:|---:|
| 相同拟合与早停样本 | 普通 RNN | 0.46343 ± 0.00257 | 0.16777 | 0.15197 | 0.47407 | 0.75293 |
| 相同拟合与早停样本 | 排序 RNN | 0.46209 ± 0.00152 | 0.16867 | 0.15632 | 0.46227 | 0.76259 |
| 相同完整外层训练样本 | 线性岭回归 | 0.47642 ± 0 | 0.22886 | 0.20399 | 0.51776 | 0.66672 |
| 相同完整外层训练样本 | 非线性特征岭回归 | 0.48205 ± 0.00091 | 0.21854 | 0.19507 | 0.51866 | 0.67165 |

排序 RNN 的 MAE 和 Spearman 仅有小幅变化，弱组误差降低，但强组误差升高，不能据此断言整体改进。非线性模型在本次固定配置下的 MAE、Pearson 和 Spearman 均不如其线性对照；这不代表所有非线性方法都无效。两个新模型均不替换现有融合筛选器。

## 方法

**排序 RNN。** 保留原 RNN 架构及相同外层分折和内层早停规则，训练损失为 0.5 × 均方误差 + 0.2 × 成对排序损失。每个打乱的小批次从首尾相对位置构造不重复样本对，仅当标准化对数标签相差至少 0.25 时计算排序损失；希望高强度样本得到更高预测值。该损失是排序的可微近似，不等同于直接优化 Spearman。早停仍按内部验证误差进行。

**非线性特征岭回归。** 使用位置 1-mer、位置 2-mer、全局 1–3-mer 及 GC 特征；在线性特征后增加 256 个随机傅里叶特征，模拟非线性关系。线性对照和扩展模型均使用固定 alpha=1000；带宽采用每个拟合折内 2048 对随机样本的平均平方距离确定，标准化也仅在拟合数据上完成。三次种子影响随机特征和距离抽样，线性模型是确定性的，故三次结果相同。

## 数据和解释边界

训练集 8,318 条，开发验证集 1,783 条；训练集内固定相似性簇三折，弱、中、强分组边界由训练标签的三分位数确定。RNN 每折使用约 4,436 条拟合、约 1,109 条早停；岭回归无需早停，使用该折全部约 5,545 条外层训练数据。因此跨 RNN 与岭回归的数值仅供背景参考，不能作为等训练量的模型优劣结论；两组内部的配对比较可直接参考。

排序 RNN 和普通 RNN 的 OOF 预测值标准差分别约为真实标签的 0.241 和 0.239；线性和非线性岭回归分别约为 0.414 和 0.439。较小的比值反映预测范围偏窄，但其本身不是模型正确性的证明。弱组平均误差（预测减真实）为正，强组为负，说明两端仍存在系统偏差。

开发验证集已在此前多轮开发使用，不能当成全新独立证据。验证 MAE：普通 RNN 0.44294、排序 RNN 0.44122、线性岭回归 0.45891、非线性岭回归 0.46454。测试数组仅用于输入格式检查，没有提取测试特征或计算测试指标。本轮不使用外部数据评价，也没有新增生成序列或湿实验结果。三次种子共用相同外层分折，不能作为独立测试样本，也不足以检验统计显著性。

## 复现

使用 Python 3.11+ 和项目依赖，将 `DATA_DIR` 设为课程序列数组所在目录：

```sh
for seed in 20260912 20260913 20260914; do
  OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 VECLIB_MAXIMUM_THREADS=1 \
    python scripts/evaluate_ranking_rff.py --data-dir "$DATA_DIR" --seed "$seed" \
    --output "reports/m4_ranking_rff_seed_${seed}.json" --checkpoint-dir outputs/m4_ranking_rff
done
python scripts/summarize_ranking_rff.py
python -m unittest discover -s tests -q
```

单种子重复运行得到逐字节相同的 JSON 和逐数组相同的两个模型文件；不同机器或数值库可能产生数值差异。实验保存文件供推理使用，输出为课程标签尺度的预测对数强度，不是实测结果。排序 RNN 使用 `scripts/score_rnn_strength.py`，非线性模型使用 `scripts/score_fourier_strength.py`。完整分折与分组指标见 [汇总数据](m4_ranking_rff_summary_2026-11-06.json)及各种子 JSON。
