# M4：连续自回归生成器的位置先验尝试

## 目的与方法

现有连续自回归生成器按照目标强度、序列位置和前 3 个碱基预测下一个碱基；训练数据中某些“条件 × 位置 × 上下文”组合较少，原模型对每个碱基都加入相同的平滑计数。本轮尝试：让这些稀少上下文的平滑分布参考同一强度区间、同一位置的整体碱基分布。

两种方案保持三阶上下文、3 个条件区间及插值规则一致；原模型为 4 种碱基各加入 0.1，总平滑质量为 0.4；新方案同样使用总质量 0.4，但按该位置的训练分布分配。未见过的上下文仍使用原来的位置分布回退。因此，这次对照改变的是**已有上下文的先验形状**，不是改变平滑总量。实验规则在运行前固定，见[配置](../configs/m4_ar_position_prior_2026-11-16.toml)。

两模型都只用 8,318 条训练序列及其标签拟合。首先，在 1,783 条开发验证序列上，以每条序列的已有标签为条件，逐位置使用真实前文计算每碱基负对数似然（NLL，单位 bits/base）；越低表示模型给已有验证序列分配的平均概率越高。这是验证集上的 teacher forcing 评价，**不是给新序列测量强度**。两个模型的区间中心和位置回退分布完全一致；其中 457 条验证标签超出首尾区间中心，沿用现有模型规则截到最近中心。

其次，用训练标签的弱、中、强三组均值作为目标，每个模型、组别和采样种子生成 300 条；三种采样种子均使用同样规则。比较生成序列与同强度开发验证组的逐位置 3-mer JS 散度及 GC、组内去重和训练集精确新颖性。开发验证组按其已有标签回顾划分，生成时不使用验证标签；该验证集之前多次参与模型开发。

## 验证序列的条件 NLL

| 开发验证范围 | 原均匀先验 | 新位置先验 |
|---|---:|---:|
| 全部序列 | **1.923357** | 1.924308 |
| 弱标签组 | **1.918157** | 1.918923 |
| 中标签组 | **1.925263** | 1.925837 |
| 强标签组 | **1.926416** | 1.927930 |

本次固定设置下，新方案的总体和各标签组 NLL 均略高。差异很小，不能据此声称差异具有统计显著性，也不能推广到其他先验强度或更长上下文。

## 生成序列的局部分布

下表为每组 300 条、三个采样种子的逐位置 3-mer JS 简单平均；参考是相应开发验证标签组，越低表示所统计的局部 3-mer 分布越接近该参考。

| 输入目标 | 原均匀先验 | 新位置先验 |
|---|---:|---:|
| 弱 | **0.046888** | 0.046957 |
| 中 | 0.044792 | **0.044760** |
| 强 | **0.045935** | 0.045960 |

两方案的分布距离非常接近，中目标略低、弱和强目标略高；这是有限样本上的描述，不能称为稳定改进。18 组各 300 条序列均为合法 50 bp、各组内无完全重复，且没有与训练序列完全相同的记录。这些检查不代表候选具有启动子功能，也不保证与全部生物数据库无重复。采样只改变采样种子，训练集和拟合方法未重复变化。

## 结论与边界

位置先验在这一固定平滑质量下没有改善主要的开发验证 NLL，也没有产生明确的局部分布改进，因此**暂不替换原连续自回归生成器**。本次只比较一个先验强度，不能说明所有位置先验或其他回退机制均无效。开发验证数据已用于项目早期选择和反复评价，不是独立最终测试；课程测试集早期曾被查看，本轮未提取其特征或计算指标。NLL、局部结构与目标标签不能代替对生成序列的实际表达强度或启动子功能测量。

新增测试核验先验总量、稀少上下文的分布、回退和确定性采样；全部 60 项测试通过。独立计数实现复核 20 条验证序列的两种 NLL、全部 1,783 条汇总以及 5,400 条生成序列合法性和 GC；完整实验重复运行，JSON 和两份 CSV 完全一致。完整分组与逐种子数据见[JSON](m4_ar_position_prior_2026-11-16.json)；`outputs/m4_ar_position_prior/` 内为本地研究样本及 NLL 记录，按仓库规则不上传。

## 复现

`DATA_DIR` 指向课程原始大肠杆菌序列和标签数组所在目录，环境使用 JSON 所记录的 NumPy 版本：

```sh
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 VECLIB_MAXIMUM_THREADS=1 \
python scripts/evaluate_ar_position_prior.py --data-dir "$DATA_DIR" \
  --output reports/m4_ar_position_prior_2026-11-16.json \
  --samples outputs/m4_ar_position_prior/samples.csv \
  --nll-csv outputs/m4_ar_position_prior/validation_nll.csv
```
