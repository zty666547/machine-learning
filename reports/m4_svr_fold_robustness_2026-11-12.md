# M4：SVR 对训练集内部分折的敏感性

## 目的与方法

先前仅在一套相似性簇三折中观察到 RBF SVR 的总体 MAE 低于岭回归，但强组误差更高。本轮固定同一位置 1-mer/2-mer、全局 1–3-mer 与 GC 特征、SVR 和岭回归参数，新增两套相似性簇分折；预先固定规则见[配置](../configs/m4_svr_fold_robustness_2026-11-12.toml)。

每套三折中，两种方法使用相同的外层训练样本和同一折外评价样本。岭回归 alpha=1000；SVR C=1、epsilon=0.1、gamma=`scale`，特征标准化与 gamma 均仅由当折训练数据确定。原分折的模型结果复用[此前记录](m4_rbf_svr_2026-11-09.md)，本轮重新训练两套新分折；原结果与新增结果核对数据摘要、模型配置、NumPy 和 scikit-learn 版本。新增分折与原分折、以及彼此之间的样本分配均不相同。

## 结果

| 分折种子 | 岭回归 MAE | SVR MAE | 岭回归 Spearman | SVR Spearman | 岭回归强组 MAE | SVR 强组 MAE |
|---|---:|---:|---:|---:|---:|---:|
| 20261029（原） | 0.47642 | 0.45760 | 0.20399 | 0.22766 | 0.66672 | 0.70981 |
| 20261110（新） | 0.47581 | 0.45747 | 0.20621 | 0.22487 | 0.66532 | 0.71055 |
| 20261111（新） | 0.47784 | 0.45978 | 0.19931 | 0.21908 | 0.67160 | 0.71362 |

三套分折的 MAE 均值分别为岭回归 0.47669、SVR 0.45828；弱组 MAE 均值分别为 0.51652、0.47387；强组 MAE 均值分别为 0.66788、0.71133。SVR 的总体、弱组误差和 Spearman 在三套分折中都优于该岭回归配置，强组 MAE 则三次都更大。新增两套分折中，SVR 绝对误差更低的样本比例分别为 57.18% 和 56.31%，仅为描述性统计。

这一结果支持上述取舍在这三套训练内部分折中持续存在，但这不是三份独立数据：相同样本多次参与训练与评价，不能据此声称统计显著，也不能保证跨实验泛化。只比较了每种方法的一组固定参数，不能得出模型在最佳参数下的普遍优劣。

## 边界与复现

只对 8,318 条训练样本计算特征、训练和指标；开发验证和测试数组仅由数据加载器检查格式，不参与本轮计算。课程测试集此前曾被查看。无新外部评价、湿实验或推理检查点；当前融合筛选器未替换。强弱分组是按训练标签三分位数对预测结果回顾，不能事先知道待生成序列的真实强度组。

在 NumPy 2.5.4、scikit-learn 1.9.1 环境下：

```sh
for seed in 20261110 20261111; do
  OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 VECLIB_MAXIMUM_THREADS=1 \
    python scripts/evaluate_svr_fold_robustness.py --data-dir "$DATA_DIR" --fold-seed "$seed" \
    --output "reports/m4_svr_fold_${seed}.json"
done
python scripts/summarize_svr_fold_robustness.py
```

[汇总结果](m4_svr_fold_robustness_2026-11-12.json)与两份新增分折 JSON 记录数据摘要、版本和分组指标；跨数值环境可能有差异。
