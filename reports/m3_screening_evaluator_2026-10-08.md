# M3：候选序列筛选验证器完善

阶段记录日期：2026 年 10 月 8 日。本轮目标不是建立最终实验强度测量器，而是为 M3 生成候选提供一个更稳定的**相对筛选分数**。训练只使用训练集，融合权重只通过验证集选择；本轮没有加载或使用测试集。

## 为什么需要融合

单独的 motif CNN 可以利用局部模式与位置，但预测范围明显收缩；全局 k-mer 岭回归和位置岭回归各自较弱，却包含与 CNN 不完全相同的序列统计信息。因此将三者的预测加权融合，并以验证集 Pearson 为主选择指标。

## 验证集结果

| 验证器 | MAE | RMSE | Pearson | Spearman |
|---|---:|---:|---:|---:|
| motif CNN | 0.4317 | 0.5826 | 0.2607 | 0.2338 |
| 全局 k-mer 岭回归 | 0.4458 | 0.5820 | 0.2326 | 0.2192 |
| 位置岭回归 | 0.4638 | 0.6020 | 0.2168 | 0.2075 |
| **M3 融合筛选验证器** | 0.4316 | **0.5737** | **0.2866** | **0.2628** |

选定权重为：

```text
motif CNN             0.5
全局 k-mer 岭回归      0.4
位置岭回归             0.1
```

与单独 CNN 相比，验证 Pearson 提高 `0.0259`，Spearman 提高 `0.0290`。这表示对候选的相对排序能力有所改善；MAE 几乎不变，因此它并未解决所有强度估计误差。

## M3 中如何使用

建议流程：先由生成器产生一批候选，再使用该融合分数对同一目标条件下的候选排序，优先检查得分更接近目标组范围、同时通过 motif、新颖性和多样性检查的序列。

输出包含：融合筛选分数、按训练集三等分边界得到的弱/中/强筛选标签，以及三个组成模型的分数，便于追溯。

## 严格限制

- 该分数是 **M3 候选排序工具**，不是独立实验测得的表达强度；
- 它不能消除 CNN 对弱、强样本向中间值收缩的问题；
- 当前测试集已在早期探索中查看过，因此本轮不再报告或依据测试集选择融合权重；
- 最终的生物学强度仍需独立实验或课程提供的外部预测器验证。

## 复现与打分

选择权重：

```bash
python scripts/tune_m3_screening_evaluator.py \
  --data-dir /path/to/promoter/strenth/data
```

候选文件每行放一条 50 bp 的 A/C/G/T 序列，然后运行：

```bash
python scripts/score_m3_screening_evaluator.py \
  --data-dir /path/to/promoter/strenth/data \
  --candidate-file candidates.txt \
  --output outputs/m3_screening_scores.csv
```

原始验证集调参结果见 [JSON 文件](m3_screening_evaluator_tuning.json)。
