# M4 强度预测器：梯度提升树探索

## 方法

上一轮的随机树改善了整体 MAE，但预测范围变窄且强弱两端误差上升。本轮换用梯度提升树：后续树逐步拟合已有预测的残差。固定 100 轮、学习率 0.05、每棵树最多 15 个叶节点、叶节点至少 30 条、L2 正则 1、每轮随机使用一半特征；不使用早停。配置在结果产生前固定，见[实验配置](../configs/m4_boosting_2026-11-08.toml)。

采用和线性岭回归相同的位置 1-mer、位置 2-mer、全局 1–3-mer 和 GC 特征，外层每折均使用全部训练样本（约 5,545 条）。报告训练集相似性簇三折折外预测、三个种子的均值：

| 指标 | 线性岭回归 | 梯度提升树 |
|---|---:|---:|
| MAE | 0.47642 | 0.46504 |
| Pearson | 0.22886 | 0.23597 |
| Spearman | 0.20399 | 0.21229 |
| 弱组 MAE | 0.51776 | 0.53746 |
| 中组 MAE | 0.24468 | 0.18135 |
| 强组 MAE | 0.66672 | 0.67621 |
| 预测标准差 / 标签标准差 | 0.41419 | 0.22125 |

提升树总体 MAE 较低，主要伴随中组改善；弱组和强组误差均升高，预测范围也明显收窄。与上一轮 Extra Trees 的现象相似，不能认定全面改进。开发验证集 MAE 分别为 0.45891 和 0.44314、Pearson 为 0.22030 和 0.25529；开发验证集已被反复使用，不能视为独立评价。

## 数据边界与复现

训练集 8,318 条、开发验证集 1,783 条。弱、中、强分组边界按训练标签三分位数确定；三个种子共用外层分折，不是独立测试。测试数组仅由加载器检查格式，未提取测试特征或计算测试指标；没有使用外部数据或湿实验。RNN 的训练和早停样本数不同，不能直接作等训练量对照。当前模型不替换融合筛选器，未导出推理检查点。

实验环境 Python 3.12、NumPy 2.5.4、scikit-learn 1.9.1。配置好依赖及 `DATA_DIR` 后：

```sh
for seed in 20260912 20260913 20260914; do
  OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 VECLIB_MAXIMUM_THREADS=1 \
    python scripts/evaluate_boosting.py --data-dir "$DATA_DIR" --seed "$seed" \
    --output "reports/m4_boosting_seed_${seed}.json"
done
```

各结果 JSON 包含数据摘要、环境版本及完整总体和分组指标，跨环境可能存在数值差异。
