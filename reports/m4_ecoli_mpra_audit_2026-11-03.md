# M4：大肠杆菌外部报告基因数据与序列重叠核查

日期：2026-11-03。本轮目标是寻找后续可用于考察强度预测器跨实验表现的数据，核查序列、坐标、测量方式与课程数据的重叠。本轮只做数据审计和候选筛查，**没有用这份数据评价、训练或选择预测器，也没有验证生成序列的实际活性**。

## 1. 找到的数据及其用途

[Urtecho 等人的研究](https://elifesciences.org/reviewed-preprints/92558)用大肠杆菌基因组整合的高通量报告基因实验，对大量候选 TSS 附近的 150 bp 序列测量活性。研究者给出 [公开代码和处理结果](https://github.com/KosuriLab/ecoli_promoter_mpra/tree/484abdb6ba2d398501009ee6eb25ca7f190d3b4c)。其 TSS 文库综合了包括 Thomason 研究在内的来源；因此，虽然实验测量是另一项研究进行的，**序列不能默认与我们的课程数据独立**。

本轮核查该仓库固定版本 `484abdb6ba2d398501009ee6eb25ca7f190d3b4c` 的两个文件：

- [TSS 活性数据](https://github.com/KosuriLab/ecoli_promoter_mpra/blob/484abdb6ba2d398501009ee6eb25ca7f190d3b4c/processed_data/endo_tss/lb/rLP5_Endo2_lb_expression_formatted_std.txt)：含序列、坐标、方向、经处理的报告实验读数和活性标签。
- [U00096.2 基因组序列](https://github.com/KosuriLab/ecoli_promoter_mpra/blob/484abdb6ba2d398501009ee6eb25ca7f190d3b4c/ref/U00096.2.fasta)：用于核对表中片段与坐标、链方向是否一致。

外部读数是报告实验的处理值；课程标签是另一种实验背景下的转录水平代理，两者的数值尺度、测量条件和序列上下文不同。外部实验测的是完整 **150 bp** 片段的活性，而当前模型只接收其中的 50 bp，即使提取出相同长度，也不代表它们是同一个预测任务。

## 2. 数据核验与排除

文件共有 17,767 行，包括 17,189 行 `tss`、96 行阳性对照和 482 行阴性对照。本轮只分析 `tss` 类，未把阳性、阴性对照混入：

| 逐行位置核验结果 | 记录数 |
| --- | ---: |
| 与 U00096.2 中标注的 150 bp 区间及链方向一致 | 17,142 |
| 片段序列与标注的基因组区间不一致 | 45 |
| 区间超出参考 FASTA 的线性坐标范围 | 2 |
| TSS 记录合计 | 17,189 |

这里的“不一致”是本次依据公开文件和参考版本计算出的现象，**不推断其具体成因，也不认定原研究有错误**。两条越界记录可能涉及线性参考的边界问题，但当前未完成原因核实。以上 47 条已保留在逐条审计文件中，并排除出本轮重叠统计。

在通过核验的 17,142 条中，按其 150 bp 片段中记录的 TSS 对齐，提取片段下标 `[70:120]` 作为 50 bp 上游窗口。脚本同时对正链和负链进行坐标、反向互补和序列核验。窗口有 17,013 个不同序列，说明行数与不重复序列数不同。

## 3. 重叠检查方法

课程数据全量为 11,884 条，包含训练、验证和测试划分。本轮测试集序列仅用于统计重叠，**未用于计算模型表现或选择模型**；由于项目早期曾查看测试结果，也不能把它称为从未接触过的最终测试集。

使用两种互补的筛查，均比较原方向及反向互补方向：

1. **固定位置比较**：对 50 bp 窗口逐位比较，允许最多 5 处不同，即至少 45/50 位相同。该方法不允许插入、删除或位置错开。
2. **位置偏移检查**：将外部 50 bp 窗口相对当前截取位置向前或向后移动最多 5 bp，再寻找完全相同的课程序列；此项检查只找完全匹配，不搜索偏移后的近似匹配。

阈值是为了排查重叠而采用的工作规则，不代表有统一的生物学独立性标准；同一序列可能与多个课程划分中的不同记录匹配，因此按划分统计不能简单相加。

## 4. 主要结果

以下结果均以位置核验通过的 **17,142 条外部记录**为分母：

| 筛查结果 | 外部记录数 |
| --- | ---: |
| 固定窗口与课程序列完全一致（只看原方向） | 4,918 |
| 固定窗口与课程序列完全一致（含反向互补） | 4,944 |
| 固定窗口与课程序列至多相差 5 个碱基（含反向互补） | 4,954 |
| 允许窗口偏移 ±5 bp 后，与课程序列完全一致（含反向互补） | 10,869 |
| 两项筛查均未发现匹配的候选记录 | 6,264 |

偏移完全匹配的 10,869 条中，有 4,944 条在偏移 0 时即匹配；按绝对偏移最小、再按偏移值排序，另有 5,421 条的最近匹配偏移为 **−1 bp**。这提醒我们：仅凭一种 TSS 对齐约定计算重叠会漏掉不少相近片段。造成 −1 bp 偏移的原因仍未逐条核实，不能直接认定是课程数据或公开数据的坐标错误。

按课程划分看，偏移 ±5 bp 内有完全匹配的外部记录分别涉及训练集 7,605 条、验证集 1,688 条、测试集 1,674 条；记录可能同时涉及多个划分，不能将这三个数字相加当作独立样本总数。

6,264 条通过本轮重叠筛查的候选记录包含 6,227 个不同的 50 bp 窗口，其中 881 行被原研究标记为 active、5,383 行标记为 inactive。它们**只是待进一步审查的候选集，不是已证明独立的测试集**：本轮没有检查偏移后的近似序列、带缺口比对、基因组相邻区域关系或所有潜在同源性。

此外，通过位置核验的记录中有 6,458 个处理后的活性值为负；6,264 条候选中有 2,526 个负值。不能直接对这些值取 `log10`，也不能未经处理就与课程标签拼接或按相同数值尺度计算 MAE。原研究给出的 `active/inactive` 标记依赖其自己的实验阈值，不能自动等同于课程数据的强弱分组。

## 5. 对后续实验的建议

- 把本轮结果作为**外部数据可行性与污染排查**，不要直接声称已经完成外部验证。
- 如继续使用，应先固定数据排除规则和评价方案，进一步检查偏移近似匹配、序列关系及重复窗口；保留原始数据来源和排除清单。
- 在不同实验尺度下，可研究预测分数与外部读数的排序关系，并单独探索区分原研究 active/inactive 的能力，但须说明 50 bp 输入与 150 bp 测量的上下文差异、类别不平衡及标签尺度限制。不能通过外部数据反复挑选模型后，再把同一结果称为独立最终测试。
- 即使未来在该外部数据上得到结果，它评价的也是**已有外部序列**上的跨实验表现，不能代替对本项目新生成序列进行实验测量。

## 6. 文件与复现

在仓库根目录运行。以下固定版本下载链接分别对应上面的两个上游文件；脚本会检查它们的 Git blob SHA-1，不匹配时停止。

```bash
mkdir -p outputs/m4_external/source
curl -L --fail -o outputs/m4_external/source/tss_expression.txt \
  https://raw.githubusercontent.com/KosuriLab/ecoli_promoter_mpra/484abdb6ba2d398501009ee6eb25ca7f190d3b4c/processed_data/endo_tss/lb/rLP5_Endo2_lb_expression_formatted_std.txt
curl -L --fail -o outputs/m4_external/source/U00096.2.fasta \
  https://raw.githubusercontent.com/KosuriLab/ecoli_promoter_mpra/484abdb6ba2d398501009ee6eb25ca7f190d3b4c/ref/U00096.2.fasta
python scripts/audit_ecoli_mpra_external.py \
  --data-dir /path/to/promoter/strenth/data \
  --mpra outputs/m4_external/source/tss_expression.txt \
  --genome outputs/m4_external/source/U00096.2.fasta
python -m unittest discover -s tests -v
```

机器可读汇总为 [审计 JSON](m4_ecoli_mpra_audit_2026-11-03.json)，逐条结果输出到 `outputs/m4_external/urtecho_tss_overlap.csv`。该 CSV 标注位置核验状态、固定窗口最少错配数、偏移完全匹配及候选筛查结果；未发现匹配处的空值表示“本规则下没有命中”，不是错配数为零。输出目录及上游数据不提交 Git，可按命令重新生成。
