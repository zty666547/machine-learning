# M4：现有强度筛选器的外部数据探索

日期：2026-11-03。本文依据计算前固定的 [评价方案](m4_external_evaluation_protocol_2026-11-03.md)，考察现有融合筛选器在另一项报告基因实验中的排序表现。该批数据经过多轮重叠排查，仍不能证明完全独立；本轮属于跨实验探索，**不是对生成序列的生物学验证**。

## 1. 总体结果

对 1,552 条外部实验记录，现有融合筛选分数与原始处理后外部实验活性的 **Spearman 秩相关系数为 0.1360**，呈较弱的正向排序关系。按外部研究自己的 active/inactive 标记评估，**AUROC 为 0.7887，平均精度 AP 为 0.2495**；样本中的 active 比例为 0.0625。

这说明在本批筛选过的外部样本及其原标签上，分数对 active/inactive 有一定排序区分；但对连续实验值的整体排序关系较弱。该结果不表示预测强度准确，不是分类准确率，也不能证明生成序列具有某种真实强度。

## 2. 数据和固定方案

- 外部候选使用上一轮 6,258 条记录中，到任何已定位课程 50 bp 窗口的最小基因组间隔严格大于 200 bp 的 1,552 条，共 1,541 个不同 50 bp 输入；相应逐条数据文件 SHA-256 固定在协议中。
- 97 条标记为 active、1,455 条标记为 inactive，阳性比例 6.25%。757 条外部处理值为负、没有零值、795 条为正；全部按原数值参与秩相关，不取对数。
- 上游报告基因实验测量完整的 150 bp 片段，预测器只看到对应的 50 bp 窗口；外部实验和课程数据的测量体系及标签尺度不同。预筛选不包括所有带插入、删除的相似性及全部同源关系，也不能保证绝对独立。
- 预测器沿用 M3 固定配置：motif CNN、全局 1–3-mer 岭回归、位置岭回归，权重分别为 0.5、0.4、0.1，随机种子 20260912。训练集用于拟合，开发验证集用于 CNN 早停；外部数据不用于拟合、校准、权重选择或模型选择。复现得到的开发验证 Pearson 为 0.2866，与先前基线一致。该验证集此前已用于模型选择，不是新测试集。
- 课程测试序列只用于先前的重叠和基因组邻近性排查，没有参与本轮模型训练或指标计算。课程测试集在更早期曾被查看，不应称为从未接触的最终测试集。

## 3. 主要结果：按 1,552 条实验记录

| 评分方案 | Spearman | AUROC | AP |
| --- | ---: | ---: | ---: |
| 固定融合筛选器 | 0.1360 | 0.7887 | 0.2495 |
| motif CNN 组成分数 | 0.1021 | 0.7482 | 0.1952 |
| 全局 k-mer 岭回归组成分数 | 0.1636 | 0.7774 | 0.2301 |
| 位置岭回归组成分数 | 0.0680 | 0.6788 | 0.1292 |

后三行是**预先列出的探索性组成分数**，不是依据这批外部结果重新选择模型或调整融合权重的理由；此表没有证明组件差异具有统计显著性。

指标解释：

- **Spearman** 比较预测分数的排序与外部连续实验值的排序。0.1360 表示在本批数据上的整体排序关系较弱；相同数值使用平均名次。
- **AUROC** 反映随机选取一条 active 与一条 inactive 时，active 被排在前面的能力；并列分数按半次计。0.7887 不等于“78.87% 的序列被正确分类”。
- **AP** 将不同分数阈值下的 precision–recall 关系按召回变化做阶梯式汇总，同分数一起处理；它不是某个固定阈值下的准确率或精确率。本批阳性比例 0.0625 可作为类别不平衡的参考，不能将 AP 直接解释为实验成功率。

本轮未设定打分阈值、候选导出比例、置信区间或显著性检验。记录之间可能有重复或其他相关性，不能假设 1,552 条全都是互相独立的观察。

## 4. 唯一 50 bp 输入的敏感性检查

按照计算前约定，对相同 50 bp 输入使用外部处理值的中位数作为一个统计汇总；若组内 active/inactive 标签不一致则停止。中位数不表示不同 150 bp 上下文是同一次实验，也不是对原始记录的替代。

| 分析单位 | 数量 | active | Spearman | AUROC | AP |
| --- | ---: | ---: | ---: | ---: | ---: |
| 实验记录 | 1,552 | 97 | 0.1360 | 0.7887 | 0.2495 |
| 唯一 50 bp 输入，中位数汇总 | 1,541 | 97 | 0.1349 | 0.7873 | 0.2495 |

本次两种统计下数字接近，说明按所选的中位数汇总处理重复输入时，主要描述性结果变化较小；这不排除其他序列关系、基因组邻近或实验上下文造成的依赖。

## 5. 核验与后续

代码单元测试覆盖排序并列、AUROC、阶梯式 AP、负值和重复输入冲突；额外使用逐对 AUROC、暴力排名和独立阈值累积重新计算主要指标，结果一致。重新运行整轮固定预测器训练和评分后，结果 JSON 与逐条 CSV 均逐字节一致。

本批数据及其结果已进入开发期分析，今后不能再把相同数据称为“从未查看过的最终独立测试集”。下一步优先进一步核查带插入、删除的近似序列关系和外部实验上下文，明确是否能够获得真正独立的新数据或对生成候选进行实验测量。在此之前，保留现有融合筛选器，不根据这次探索结果更改权重。

## 6. 复现

先按此前 [基因组邻近性记录](m4_ecoli_genome_proximity_2026-11-03.md)生成固定的逐条候选文件，再执行：

```bash
export OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 VECLIB_MAXIMUM_THREADS=1
python scripts/evaluate_ecoli_external_screening.py \
  --data-dir /path/to/promoter/strenth/data \
  --candidate-csv outputs/m4_external/urtecho_genome_proximity.csv
python -m unittest discover -s tests -v
```

汇总见 [JSON 结果](m4_external_screening_results_2026-11-03.json)，逐条分数生成于 `outputs/m4_external/screening_scores_2026-11-03.csv`。该 CSV 是本地派生文件，不随 Git 提交。
