# Processed data

Processed arrays and temporary caches are generated by scripts and ignored by Git.

`scripts/prepare_data.py` validates `data/raw/promoter.npy` and
`data/raw/gene_expression.npy` and writes the normalized copies here:

- `promoter.npy` — upper-case fixed-width unicode sequences, 50 bp each;
- `gene_expression.npy` — `float64` positive strengths, unchanged values.

Load these files with `promoter_ml.data.load_promoter_arrays`, or pass this
directory as `--data-dir` to the training scripts.

Formal split definitions belong in `data/splits/` as small, reviewable index
files, not here.
